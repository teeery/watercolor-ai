# 06 · 接入实测与反思（介质升级 M0-M5 → 笔刷 v2.0 → agent/copy 实测 → 反思与论文 → v0.3.0 存档）

> 阶段范围：Phase 0 交付之后到最小发布版 v0.3.0 存档（2026-08-16 ~ 08-17，两个并行会话 + 收尾会话）。
> 主线：引擎从"五工件成立"升级到"可画的介质"（M0-M5），笔刷动力学重写（v2.0），LLM 通过 stroke 协议真正画了两幅画（agent 三柿子 / copy 乡村田野），然后撞上平台期，五轮反思把病灶推到结构级，最后以论文稿 + 存档收工。

## 1. 双会话并行制度（08-16）

- 做了什么：brush（笔刷 v2.0）与 medium-upgrade（介质 M0-M5）两个会话在同一 checkout 并行开发，立 `docs/COORDINATION.md` 契约：目录所有权、路径级 `git add`、禁切分支、commit 前缀归属、接口接触点显式化。
- 为什么：两线工作量大且互不依赖，串行太慢；共用 checkout 有冲突风险，需要规则。
- 结果：15+ 个 commit 线性推进、零冲突；契约本身沉淀为可复用工作方式。
- 教训：并行安全的代价是纪律成本；接口接触点（如干笔 × σ 钉扎的水量门槛）必须显式写成文字，否则会话之间靠猜。

## 2. 介质升级 M0-M5（medium-upgrade 会话）

- **M0 位级确定 + 性能**（`perf(M0)`）：活跃集重构 + 静止短路 + 性能仪表——同一输入位级复现，成为后续所有"干预对照"实验的地基。附 Curtis 复核修复两处引擎 bug（沉积高度符号、边缘极性）。
- **M1 各向异性纸纹**：MoXi 主机制（σ 钉扎 / κ 变渗透率 / 阻滞 / 渐变固着），湿铺边缘沿纤维爬出毛边/toe。vision 7.5。
- **M2 岸线算子**：蒸发驱动向内输运 → 深色水线 + 近岸透明带 + 外侧浅线；**M2.1-M2.4**：宏观侵蚀破圆（杀"标准椭圆"）+ bloom 曲率驱动圆瓣化 + rim 调制。vision **8.5 定稿**。
- **M4 廉价五件**：盐花 / 硬边 / 纸纹三档预设 / 重力淌色 / lift 堆挤——四件半成立后 M4.1-M4.3 收尾（盐花臂宽、滴流机制、纸纹分层）。
- **M5 颜料物性四字段**：质量 / 沉降 / 容纸度 / 再湿率 → 湿中混色互渗、粒重分离、再湿重溶。vision **8.8 全场新高**。
- 集成调参：色彩线 × M0-M5 合体后四件修复（`de48397`）。
- 教训：升级顺序是"先物理归位再加效果"——bugfix 物理归位 → M1 7.5 → M2 8.5 → M5 8.8，每一步都建立在上一步的确定性之上。

## 3. 笔刷动力学 v2.0（brush 会话）

- 做了什么：从"泪滴戳"旧模型重写为四层架构——水库（画笔储水量预算）/ 运动层 / N 毛模型（阻尼追随 + 离心甩尾）/ 发射沉积。分桶沉积（max-blend、按路径顺序分段）杀掉"串珠/印章链"病根；一笔内时间（interleave）让干笔前段真干透、尾部断纹飞白成立。
- 为什么：旧笔触是"圆形贴图"，运笔同模、无干湿变化——物体笔触 4-5 分的根因之一。
- 结果：十一轮修复 + 面板渲染口径调优；干皴硬角、毛尖折线、飞白丝状拉伸等全部落地；干笔验收 7 分。
- 教训：分桶沉积的量化档位会累积成串珠——"每格只取最高档"与"沿路径连续分段"两个修法分别治标与治本；后者（无量化）才是病根解。

## 4. 色彩线四任务收尾（08-17）

- 做了什么：4 支偏色修正；实测光谱（CHSOS + Golden 数据）；双常数 KM（单常数 → 双常数）；Saunderson 修正 + 去光泽。
- 结果：24 色全强度平均 ΔE 5.5 → **3.2**；色卡视觉 7.2 → **8.5**（约 17-18 支可盲认）。
- 出处：`chronicle/03`、`04` 的延续；细节在 `docs/engine-js.md` 与色彩线 TASK 报告。

## 6. stroke 协议 v0.3 + agent 自主作画《三个柿子》（08-17）

- 做了什么：协议加 `cover` 覆盖湿铺原语（背景大面积铺色）；LLM **仅通过 stroke 协议**（不碰引擎、不看渲染）写出一幅完整静物，再由 vision 批评闭环多轮修改。
- 结果：**75 笔**（glaze 41 · lift 16 · dry-brush 9 · cover 等，7630 模拟步）《三个柿子》定稿（scene 注释记录 v4→v11 共 11 版修改：接触压暗、软高光、蒂形、投影、lift 清晕……）。产物：`out/agent_still_life.png` + 作画动图 + 干燥动图；`node demo/agent-paint.js` 可复现。
- 教训（已入反思论文第〇轮）：① 决策盲区——"知道水的人不做决策，做决策的人不知道水"（双层随机偏移造出错版晕）；② 坐标是 LLM 先天弱势；③ vision 分数是噪声标量（7.0/8.2/8.8 同画三轮），但因果诊断稳定可用——真正驱动改进的是诊断不是分数。

## 7. 临摹《乡村田野》与平台期（08-17）

- 做了什么：新增 `poly` 多边形原语（硬边形体：山墙、双坡顶、瓦线、窗），以一幅乡村田野照片为参照，LLM 分解 83 笔笔序（cover 23 / poly 8 / wet-wash 6 / glaze 6 / dry-brush 25 / spatter 7 / lift 8，6740 步）+ 全记录运行器（每笔快照 + 每 50 步帧）。
- 结果：6 轮 vision 闭环 **5.0 → 5.5 → 6.0 → 6.2 → 6.5**，收益逐轮递减（+0.5 → +0.2），**平台期实锤**。差在瓦缝、麦芒、云形、石墙砌缝这类"结构细节沿对象生长"的笔法；介质物理全部在场。
- 教训：批评质量没变差，是"画→批→改"循环本身的收益在收敛——由此触发反思小论文。

## 8. 反思小论文：五轮病灶推演（08-17）

- 做了什么：把平台期当病例，五轮推演完整存档于 `docs/reflection-painter-loop.md`（每轮错判与修正都保留，不事后诸葛亮）：本会话四病灶判读 → GPT 两轮互补诊断 → 逐项接受/修正/保留 → 终局裁决。
- 结论（病灶）：① 决策者无反事实能力（世界模型不参与决策）；② 逆解是分布不是函数，纯搜索收敛律被锁死；③ 视觉运动信息被迫过语言窄道；④ 价值是层级调度不是标量；⑤ 前提性——可画性未验证（动作基底 × 介质动力学的可达域未知）；⑥ 笔非原子（缺笔内闭环）。
- 处方：以引擎真实状态为总线，训练"状态锚定的世界模型 + 多模态逆策略 + 可恢复性价值模型"，LLM 只管意图（接口是 Z），微控制器骑引擎步进时钟。"搜索产生老师，学习摊销搜索，在线规划纠正学习。"
- 下一步第一块多米诺：**Oracle 1 —— 可微平面笔触拟合《乡村田野》**（平面逼近成功与否三分支，见文档末）。
- 配套新文档：`docs/paintability.md`（十基元可画性电池 + oracle 下限）、`docs/paintable-representation.md`（可绘制表征 Z）、`docs/predecessors-agents.md`（agent 画家论文册：Intelli-Paint、Inverse Painting）。
