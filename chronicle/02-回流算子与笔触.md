# 02 · 回流算子与笔触

## 回流开花（cauliflower）六版迭代

目标：清水滴入湿区 → 深色锯齿蕾丝环 + 浅色水渍心。每版都让 vision 判案，六版教训：

| 版 | 做法 | 为什么失败 | 教训 |
|---|---|---|---|
| v5 | 径向高斯推挤（半拉格朗日） | 位移剖面"解压"：心部小、前沿大，颜料摊薄 | 要堆积必须压缩 |
| v6 | 压缩式剖面 | 采样点穿过中心拉到对侧颜料，心浓边淡 | 径向采样须钳在中心 |
| v7 | 径向钳位取样 | **均匀场上推均匀颜料 = 还是均匀**（插值不守恒） | 显式搬运才是正道 |
| v8 | 显式搬运溶液 P → 前沿 | 只搬溶液；滴落时 65% 已沉积为 D | 再润湿会重溶颜料，D 也要搬 |
| v9 | P+D 同搬 | 单格四舍五入 → 像素阶梯、细线如描边 | 双线性溅射 |
| v10+ | 双线性溅射 + 解析闭环增强 + 随角度滴心稀释 + ghost ring + 外推光环 | 成 | 闭环由构造保证；滴心稀释要随角度，否则切进花瓣 |

- 结果：特写 **6.5-7/10**（闭环蕾丝 + 浅心成立），全景 6/10。细节见 `docs/engine-js.md`。
- 咖啡环、干燥时间线（10 秒真实蒸发 → 水痕"长出来"）同期完成。

## 去"圆形"之役（你问"为什么都是圆的"）

三层原因 + 对应修复：

1. **协议层**：湿铺只有椭圆 region 一种形状 → 新增 **ribbon 条带扫笔**（路径 + 宽度插值 × 压力包络（入锋窄→腹宽→收笔尖）× 沿程抖动，Chaikin×2 圆角）。
2. **笔触层**：干皴是圆章连串 → **泪滴戳**（头圆尾尖）+ 间距/朝向抖动 + 沿笔势条状飞白。
3. **物理层**：扩散各向同性 → 部分缓解（笔势定方向）；彻底解决需各向异性纸纹（未做）。

- 树干"毛毛虫"根治方案：连续 ribbon 骨干 + 树皮纹理 `clip: "last-ribbon"` 裁剪在骨干内。
- 结果：vision 确认"树干不是毛毛虫了""尖角基本消失"；全景稳定 6/10，背景 8 分、物体 4-5 分。

## GIF 电视雪花（修案）

- 现象：动图成彩条色块。用 Pillow 的 C 解码器源码当判官，逐位 diff 编码/解码码序列定位。
- 根因两个：① 字典满 4096 未发 clear 重置（12 位码溢出）；② 码宽切换早一码（须 `dictSize === (1<<codeSize)+1`）。
