# 04 · 光谱色彩与分层重构

## 光谱色彩系统（第二次色彩革命）

- **数据**：CIE 1931 2° 观察者（1nm，400-700）+ D65（5nm），取自 colour-science 开源数据集（555nm ȳ=1.000000 校验通过），嵌入 `src/color/cie-data.js`。
- **16 波段**（20nm 一档）：模拟端每通道存 K·d，渲染端逐波段 KM → XYZ → sRGB。
- **24 支颜料光谱**：按家族立形（镉类陡峭边/群青长波回升/酞菁绿肩/铁氧化物平滑上升/茜素绿谷……），坐标下降拟合到标称色（粗网格预搜索 + 预设基线防局部最优），**平均拟合 ΔE 1.9**。
- **成绩**：全强度 24 色 ΔE：RGB 5.5 → **光谱 3.2**；朱红 6.5→1.9、大红 8.4→1.9、玫瑰红 10.9→3.9。色卡 vision 7.2 → **8.5/10**（"约 17-18 支可盲认"）。
- **诚实声明**：光谱是"按家族身份的程序化近似"，非实测颜料数据。接口只要求 16 波段反射率，将来可无缝换实测光谱。
- 剩余 4 支偏色（vision 指出）：紫罗兰偏电紫、翠绿淡笔偏黄绿、生褐偏暖红、锌白偏暖——曲线微调级别，待修。

## 三个开发坑（本阶段实录）

1. 波段循环到 719nm 数组越界 → XYZ 全员 NaN。
2. 拟合器 `best` 从 Infinity 起，粗网格第一点就覆盖好预设 → 蓝系集体崩坏；改为预设先作基线。
3. 深色预设写于"直觉反射率"，而 sRGB 是 gamma 空间（黑 sRGB 0.165 ↔ 反射率 0.03），差一个量级。

## 分层重构（你的要求：松耦合，可并行异步升级）

- src 裂六部：`core/`（介质核心，通道数泛化，不知通道何义）、`color/`（颜色系统接口 + RGB/光谱双实现）、`brush/`（笔触）、`paper/`、`io/`、`studio/`（编排装配）。
- **三处升级缝**：`ColorSystem`（换颜色模型不动引擎与笔触）、`StrokePainter`（换运笔不动引擎）、`Studio`（demo/agent 层唯一依赖）。`COLOR_SYSTEM=spectral` 一键切换。
- 验收：RGB 基线全套回归通过；光谱版全套产物已出。
- 正式规格：`docs/architecture.md`。
