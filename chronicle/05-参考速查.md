## 模块与升级缝（正式规格见 `docs/architecture.md`）

```
studio → {core, color, brush}；demo → {studio, io, color}；core/brush → paper
```

- 色彩升级 = 换 ColorSystem（`color/system.js`），引擎/笔触零改动
- 笔触升级 = 只改 `brush/strokes.js`
- 介质升级 = 只改 `core/` + `paper/`
- 切换：`COLOR_SYSTEM=spectral node demo/xxx.js`

## Bug 清单（五个经典案例，修复方法见对应文件）

1. 滑动窗口 blur 初始累加整行 → 水场变负（`engine.js`）
2. 补色吸收装反 → 天空成赭褐（`engine.js` depositMask）
3. 画布边缘不蒸发 → 永恒水库（bbox 边界）
4. GIF LZW 表满不重置 + 码宽早一码 → 电视雪花（`io/gif.js`，PIL 验证）
5. 光谱波段越界 NaN + 拟合器覆盖好预设 + 反射率/sRGB 空间混淆（`color/spectra.js`）
