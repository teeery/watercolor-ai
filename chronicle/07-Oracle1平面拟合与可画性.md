# 07 · Oracle 1：平面笔触拟合《乡村田野》（可画性第一块多米诺）

> 阶段范围：v0.3.0 存档后的恢复路径第一步——回答「现有笔触表示能否重建目标」（reflection 终局裁决的 Oracle 1）。
> 主线：把 stroke 协议的几何原语抽成**无介质的平面渲染器**，用搜索拟合《乡村田野》参照，量化「表示够不够」。介质与水是另一张牌，这里只问表示。

## 1. 平面渲染器（src/paintability/flat.js）

- 做了什么：把协议的几何原语（rect/ellipse/poly/ribbon/**spatter**）剥离介质做成 `FlatCanvas`——软覆盖 mask + 颜色 + 不透明度 alpha-over 合成；纯参数化几何，无 fbm/纸纹/扩散/回流。
- 为什么：可画性要问的是「参数化几何的表示能力」；抖动（fbm）是位置的确定函数、不是自由度，几何才是。
- 结果：`src/paintability/flat.js`（与将来的十基元可画性基准共用同一套渲染）。
- 附加：`src/io/png.js` 补零依赖 PNG **解码器**（此前只有编码；加载本地参照需要）+ 双线性降采样 `resizeRGBAtoRGB`。

## 2. 拟合器（src/paintability/oracle1.js）

- 做了什么：**粗到细贪心匹配追踪**——进度 t 让「尺寸带」从大塌缩到小（先大洗铺底、后小笔补细节，镜像五阶段作画制度）；落笔点在残差最大处重要性采样；按「总残差能量」选笔；颜色闭式最优（footprint 均值校正）→ 误差单调不增。
- 为什么：先按「均值能量」选笔时，早段只画前景高频草（残差最大处），天空整片空白——证明「选笔口径」决定笔触预算分配；改「总能量」后自然粗到细（大块低中频区域总误差 > 小块高频）。
- 结果：8 笔即铺出「蓝天/黄田/底部绿」骨架（覆盖约七成），160 笔 52s。

## 3. 数据（greedy → 颜色精修 → 预算翻倍）

- 参照《乡村田野》 1728×2304 → 480×640（与引擎模拟网格同频，见 `docs/paintability.md` 嫌疑 4）。
- 误差曲线（MSE 逐通道）：1 笔 0.0488 → 3 笔 0.034 → 之后缓行——**快降后进入平台**。

| 预算 | greedy | 精修后 |
|---|---|---|
| 8 笔 | 0.0337 (14.7 dB) | 0.0330 (14.8 dB) |
| 160 笔 | 0.0272 (15.7 dB) | 0.0192 (17.2 dB) |
| 320 笔 | 0.0255 (16.0 dB) | 0.0172 (17.6 dB) |

- **颜色精修**（`refineColors`）：固定几何/alpha 下的**全局最优色**（凸最小二乘，坐标下降收敛）——160 笔从 15.66→17.17 dB，即贪心把 ~30% 误差余量留在了颜色上；精修后颜色维度清零。
- **预算翻倍**（160→320）只再 +0.47 dB → 硬地板，非预算限制。
- vision 独立评审（dsh-sight）：构图 5/10、整体相似 **4–5/10**；结构（天/田/房位置）保住，麦田纹理/树带/瓦线塌缩成「平均色」、边界全软无轮廓 →「失焦照片」。
- 对照：引擎水彩 83 笔 copy ≈ 6.5（人写笔序 + 介质纹理）> 平面拟合 ≈ 4–5。

## 4. 复证（四杠杆撬地板）

把「候选」升级为「强证据」的对照实验，全部 160 笔 + 颜色精修：

| 杠杆 | 变化 | 地板移动 |
|---|---|---|
| 颜色 | greedy → 全局最优色（凸 LSQ） | **+1.5 dB**（唯一有分量的一根） |
| 预算 | 160 → 320 笔 | +0.47 dB |
| 词汇 | +spatter 颗粒原语 | +0.18 dB |
| 词汇 | +细段硬边（soft↓，杀「失焦」） | −0.09 dB |
| 求解 | 逐笔几何局部搜索（refineGeometry） | +0.15 dB |

- 四臂词汇消融（refined PSNR）：baseline 17.16 / 锐化 17.07 / spatter 17.34 / spatter+锐化 17.32 → **添加「缺失」的颗粒与硬边原语，地板纹丝不动**。
- 几何精修：greedy 15.61 → 几何局部搜索 15.74 → 颜色精修 17.31（对照无几何 17.16）→ 局部搜索几乎不改贪心几何。
- vision 复核：定性不变（失焦平均色、4/10）；青/紫溢色与矩形硬切边为未约束调色板的视觉伪影，非主线。

## 5. 裁决（三分支：落「补表示」，性质升「强证据」）

- **落点：平面低位平台 → 补笔触表示，而非进 Oracle 2（介质）。** 三理由：颜色已全局最优（余量全在几何/频率）；预算/词汇/几何三杆都 <0.5 dB（可达域天花板 ≈17.3 dB，非「笔不够/缺词汇/贪心弱」）；vision 指认瓶颈是形状与频率，不是颜色。
- **补什么（细化处方，终证后修正）**：网格尺度重建失败，而非子网格纹理——见第 6 节终证。「补表示」= 方向性锐边原子或纹理残差通道（= 介质通道）。
- **性质 = 强证据，非数学铁证**：几何精修是弱局部搜索（4 扰 ±6px 只细段一轮），真 oracle 理论上或再挤 1–2 dB，但三杆边际收益趋势强指向「仍停留在 17–19 dB 低位」，不改分支。
- 纪律兑现：先颜色精修逼近 oracle、再预算翻倍证地板、再词汇消融 + 几何精修排除「缺词汇/贪心弱」，四条怀疑逐一排空后才把「候选」升级。

## 6. 终证（频率消融 + 硬边不透明 → 反证「频率上限」）

把「强证据」推进到工程终证的最后一击，两个实验：

**频率消融**（`boxBlurRGB` 抹平目标再拟合，`demo/oracle1-freq.js`）：

| blur r | fitPSNR（vs 抹平目标）| gapPSNR（原图 vs 抹平目标）|
|---|---|---|
| 0 | 17.32 | ∞ |
| 2 | 18.89 | 24.19 |
| 3 | 19.79 | 23.14 |
| 4 | 19.51 | 22.42 |

- MSE 拆解（r=2）：拟合离原图 0.0185 = 网格尺度失败 0.0129（大头）+ 子网格纹理 0.0038（次要）。
- **抹掉子网格纹理只能把天花板抬到 ~19.8 dB，而抹平目标本身离原图仍 22–26 dB → 地板不是奈奎斯特/频率上限，是网格尺度的重建失败。** 第 5 节「频率上限/提分辨率」判断被证伪。

**硬边 + 不透明**（`opaque`+`hard`，`demo/oracle1-hardtest.js`）：抹平目标 r=2 下软笔 18.89 / 硬边 18.65 / 硬边+不透明 18.36 dB——锐利不透明原子在手，贪心也没追轮廓，天花板不动 → 排除软剪影/低不透明度。

**六杠杆总表**（除颜色 +1.5、频率 +2.5 外全部 <0.5 dB）：颜色 / 预算×2 / spatter / 硬边 / 几何局部搜索 / 不透明度+硬边。→ 地板 ≈17–20 dB 是「平滑原子 × 贪心匹配」的**卡通/低通分段天花板**；补表示 = 方向性锐边原子或**纹理残差通道（= 水彩介质通道）**，引擎 6.5 vs 平涂 4.5 的那 2 分即此残差通道的预览。

- `node demo/oracle1-freq.js`（频率消融）→ `freq-ablation.json` / `freq_r*.png`。
- `npm run oracle1`（新增脚本）；几何精修（`geomRefine=1`）约 4 分钟。
