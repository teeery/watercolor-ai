# 07 · Oracle 1：平面笔触拟合《乡村田野》（可画性第一块多米诺）

> 阶段范围：v0.3.0 存档后的恢复路径第一步——回答「现有笔触表示能否重建目标」（reflection 终局裁决的 Oracle 1）。
> 主线：把 stroke 协议的几何原语抽成**无介质的平面渲染器**，用搜索拟合《乡村田野》参照，量化「表示够不够」。介质与水是另一张牌，这里只问表示。

## 1. 平面渲染器（src/paintability/flat.js）

- 做了什么：把协议的几何原语（rect/ellipse/poly/ribbon）剥离介质做成 `FlatCanvas`——软覆盖 mask + 颜色 + 不透明度 alpha-over 合成；纯参数化几何，无 fbm/纸纹/扩散/回流。
- 为什么：可画性要问的是「参数化几何的表示能力」；抖动（fbm）是位置的确定函数、不是自由度，几何才是。
- 结果：`src/paintability/flat.js`（与将来的十基元可画性基准共用同一套渲染）。
- 附加：`src/io/png.js` 补零依赖 PNG **解码器**（此前只有编码；加载本地参照需要）+ 双线性降采样 `resizeRGBAtoRGB`。

## 2. 拟合器（src/paintability/oracle1.js）

- 做了什么：**粗到细贪心匹配追踪**——进度 t 让「尺寸带」从大塌缩到小（先大洗铺底、后小笔补细节，镜像五阶段作画制度）；落笔点在残差最大处重要性采样；按「总残差能量」选笔；颜色闭式最优（footprint 均值校正）→ 误差单调不增。
- 为什么：先按「均值能量」选笔时，早段只画前景高频草（残差最大处），天空整片空白——证明「选笔口径」决定笔触预算分配；改「总能量」后自然粗到细（大块低中频区域总误差 > 小块高频）。
- 结果：8 笔即铺出「蓝天/黄田/底部绿」骨架（覆盖约七成），160 笔 52s。

## 3. 数据（greedy → 颜色精修 → 预算翻倍）

- 参照《乡村田野》 1728×2304 → 480×640（与引擎模拟网格同频，见 `docs/paintability.md` 嫌疑 4）。
- 误差曲线（MSE 逐通道）：1 笔 0.0488 → 3 笔 0.034 → 之后缓行——**快降后进入平台**。

| 预算 | greedy | 精修后 |
|---|---|---|
| 8 笔 | 0.0337 (14.7 dB) | 0.0330 (14.8 dB) |
| 160 笔 | 0.0272 (15.7 dB) | 0.0192 (17.2 dB) |
| 320 笔 | 0.0255 (16.0 dB) | 0.0172 (17.6 dB) |

- **颜色精修**（`refineColors`）：固定几何/alpha 下的**全局最优色**（凸最小二乘，坐标下降收敛）——160 笔从 15.66→17.17 dB，即贪心把 ~30% 误差余量留在了颜色上；精修后颜色维度清零。
- **预算翻倍**（160→320）只再 +0.47 dB → 硬地板，非预算限制。
- vision 独立评审（dsh-sight）：构图 5/10、整体相似 **4–5/10**；结构（天/田/房位置）保住，麦田纹理/树带/瓦线塌缩成「平均色」、边界全软无轮廓 →「失焦照片」。
- 对照：引擎水彩 83 笔 copy ≈ 6.5（人写笔序 + 介质纹理）> 平面拟合 ≈ 4–5。

## 4. 裁决（三分支：落「补表示」）

- **落点：平面低位平台 → 补笔触表示（形状词汇/硬边/纹理），而非进 Oracle 2（介质）。** 三理由：颜色已全局最优（余量全在几何/布局）；预算翻倍只 +0.47 dB（可达域天花板 ≈17.5 dB）；vision 指认瓶颈是形状与布局，不是颜色。
- **性质 = 候选成立，非铁证**：几何走贪心尺寸带、非真 oracle；词汇缺 `spatter`（颗粒/麦穗纹理）与 `lift`（负形减法）；颜色未约束调色板有少量青/紫溢色。复证路径见 `docs/oracle1.md`「复证」。
- 纪律兑现：没有把 greedy 当 oracle 冒称之为结论——先颜色精修逼近 oracle、再预算翻倍证地板，才下手裁决。
