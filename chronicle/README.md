# 开发日志（chronicle）

**用途**：如实记录本项目做过什么、为什么这么做、结果如何（含低分与失败）。写给人读，简短清晰，不文绉绉。

**规则**：
1. 每个文件 = 一个阶段，按时间顺序记。
2. 每条记录四要素：做了什么 → 为什么 → 结果/数据 → 教训（有则记）。
3. 评分与失败如实记录；不确定处标注。
4. 技术细节只放一句话 + 指向 docs/ 对应文档，不在日志里重复。
