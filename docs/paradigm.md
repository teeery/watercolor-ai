# 范式：agent 水彩画家

## 从哪来：三步认知路线

1. **眼睛与手**：dsh-sight 给 agent 装上眼睛（vision 工具），dsh-studio 给它装上画 SVG 的手。四个 agent 圆桌裁定："卖点不是画得更好，而是过程真实、进化可见"。
2. **实战检验**：两幅 demo（浮世绘鲸鱼 23/25、水彩榕树女孩 19/25）跑通完整"画→看→批→改"循环，证明过程诚实，也证明输出天花板是"构图正确的几何拼贴"——评分达标却平庸。
3. **诊断结论**：惊艳缺的不是轮数，是质感、光的层次、批评的粒度。SVG 白名单锁死质感；rubric 五维全是技术正确性，没有美学强度；批评是主题级（"缺背鳍"）而执行是路径级。

→ 结论：**水彩这条路，介质必须从模型手里拿走，交给引擎。**

## 三方强项与我们的除法

| | 强项 | 弱项 |
|---|---|---|
| diffusion | 采样出整张精美图片 | 过程不可见 / 不可干预 / 不可复现 |
| 水彩渲染引擎 | 水行为真实（水痕 / 毛边 / 颗粒） | 不会构图，只等一只手 |
| LLM | 意图：构图、笔序、色彩理论、技法 | 不知道水会怎么流 |

**新分工**：

- **模型管意图**：不发整幅图，发结构化的笔触指令（画什么、用什么颜料、多少水、湿纸还是干纸、什么时机）。
- **引擎管介质**：忠实渲染每笔的水行为——水痕、毛边、颗粒聚集是引擎的职责，模型不再伪造。
- **时间管叙事**：每笔带时间戳，湿区会干、水痕会成形，作画过程成为可观看的流。
- **眼睛管反馈**：每阶段 vision 看真实画布，批评细到"一个局部一笔"，agent 决定下一笔或撤一笔。

## 空象限

| | 过程可见 | 介质真实 | 自主创作 |
|---|---|---|---|
| diffusion | 否 | 风格近似 | 否 |
| 水彩引擎 | 是（需人挥笔） | 极强 | 否 |
| LLM 写 SVG（dsh-studio） | 是 | 否 | 是 |
| **agent 画家** | **极强** | **极强（引擎保证）** | **是** |

## 为什么必须是时间

水彩的三个标志性美感都是时间函数：

- **水痕（backrun / 花边）**：颜料随水扩散，湿区边缘蒸发最快，溶质回流沉积，形成深色潮线。
- **毛边（feathering）**：颜料沿纸纤维毛细渗透，边界不规则。
- **颗粒聚集（granulation）**：重颜料沉入纸谷，形成点状纹理。

静态图像（无论 SVG 还是 PNG）里不存在时间，所以"LLM 画水彩"的天花板就是假水彩。**时间线不是加分项，是护城河**：观众第一次看到水痕"长出来"，就不会再问"这是不是滤镜"。

## 两个要提前承认的天花板

1. **模型的笔触品味**（解剖、笔序、留白判断）仍弱——但 stroke 级比整幅 SVG 好修：局部错了撤一笔，不整幅重写。这直接解决 dsh-studio 的"批评粒度与执行粒度不匹配"。
2. **引擎只到"像 Procreate 笔刷"就会招黑**（"这不就是滤镜吗"）——所以干燥时间线、可暂停可回放、可干预必须做透，时间才是区别于笔刷引擎的东西。

## 继承的诚实守则

- 过程真实、进化可见；永不伪造批评；撤笔、改砸的阶段如实留在记录里。
- 会话日志即证据链（dsh-studio 的架构遗产）。
