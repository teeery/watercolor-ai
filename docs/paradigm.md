# 范式：agent 水彩画家

## 从哪来：三步认知路线

1. **眼睛与手**：dsh-sight 给 agent 装上眼睛（vision 工具），dsh-studio 给它装上画 SVG 的手。四个 agent 圆桌裁定："卖点不是画得更好，而是过程真实、进化可见"。
2. **实战检验**：两幅 demo（浮世绘鲸鱼 23/25、水彩榕树女孩 19/25）跑通完整"画→看→批→改"循环，证明过程诚实，也证明输出天花板是"构图正确的几何拼贴"——评分达标却平庸。
3. **诊断结论**：惊艳缺的不是轮数，是质感、光的层次、批评的粒度。SVG 白名单锁死质感；rubric 五维全是技术正确性，没有美学强度；批评是主题级（"缺背鳍"）而执行是路径级。

→ 结论：**水彩这条路，介质必须从模型手里拿走，交给引擎。**

## 三方强项与我们的除法

| | 强项 | 弱项 |
|---|---|---|
| diffusion | 采样出整张精美图片 | 过程不可见 / 不可干预 / 不可复现 |
| 水彩渲染引擎 | 水行为真实（水痕 / 毛边 / 颗粒） | 不会构图，只等一只手 |
| LLM | 意图：构图、笔序、色彩理论、技法 | 不知道水会怎么流 |

**新分工**：

- **模型管意图**：不发整幅图，发结构化的笔触指令（画什么、用什么颜料、多少水、湿纸还是干纸、什么时机）。
- **引擎管介质**：忠实渲染每笔的水行为——水痕、毛边、颗粒聚集是引擎的职责，模型不再伪造。
- **时间管叙事**：每笔带时间戳，湿区会干、水痕会成形，作画过程成为可观看的流。
- **眼睛管反馈**：每阶段 vision 看真实画布，批评细到"一个局部一笔"，agent 决定下一笔或撤一笔。

## 空象限

| | 过程可见 | 介质真实 | 自主创作 |
|---|---|---|---|
| diffusion | 否 | 风格近似 | 否 |
| 水彩引擎 | 是（需人挥笔） | 极强 | 否 |
| LLM 写 SVG（dsh-studio） | 是 | 否 | 是 |
| **agent 画家** | **极强** | **极强（引擎保证）** | **是** |

## 为什么必须是时间

水彩的三个标志性美感都是时间函数：

- **水痕（backrun / 花边）**：颜料随水扩散，湿区边缘蒸发最快，溶质回流沉积，形成深色潮线。
- **毛边（feathering）**：颜料沿纸纤维毛细渗透，边界不规则。
- **颗粒聚集（granulation）**：重颜料沉入纸谷，形成点状纹理。

静态图像（无论 SVG 还是 PNG）里不存在时间，所以"LLM 画水彩"的天花板就是假水彩。**时间线不是加分项，是护城河**：观众第一次看到水痕"长出来"，就不会再问"这是不是滤镜"。

## 中间表示：画家操作的不是对象

- 场景图（"天空、房屋、树、麦田"）解决语义，不解决绘画。画家真正操作的是：明度块、冷暖关系、正负形、边缘归属、透明色层、留白拓扑、笔势方向场、视觉重心、局部对比度、湿边干边的时序关系。
- 因此意图层与笔序层之间的中间表示必须是**可绘制表征 Z = {V, L, E, O, T, Q, S, M}**（明度场/色层/边缘场/拓扑/方向场/纸白/显著性/技法）。
- 对一幅水彩原作，系统的任务是**逆水彩分解**：推断这块视觉结果可能由哪几层洗色、哪次留白、哪种湿度、哪些干笔形成——与"这里是一栋房子"不是同一个问题。
- 规格与延展方向见 `docs/paintable-representation.md`。

## 三个要提前承认的天花板

1. **模型的笔触品味**（解剖、笔序、留白判断）仍弱——但 stroke 级比整幅 SVG 好修：局部错了撤一笔，不整幅重写。这直接解决 dsh-studio 的"批评粒度与执行粒度不匹配"。
2. **引擎只到"像 Procreate 笔刷"就会招黑**（"这不就是滤镜吗"）——所以干燥时间线、可暂停可回放、可干预必须做透，时间才是区别于笔刷引擎的东西。
3. **引擎可达域未证**：动作空间 + 介质动力学能稳定实现哪些形状、边缘、频率、透明层次，从未测量过——完美 AI 也画不出引擎产生不了的东西。先证可画再谈品味：`docs/paintability.md` 的基元电池 + oracle 下限。

## 继承的诚实守则

- 过程真实、进化可见；永不伪造批评；撤笔、改砸的阶段如实留在记录里。
- 会话日志即证据链（dsh-studio 的架构遗产）。

## 后续裁决：病灶级反思（临摹平台期 6.5 之后）

"三权分立"（LLM 管意图 / 引擎管介质 / vision 管反馈）的正确性已被 M0-M5 验证，但它同时制造了结构性暗面：**决策者与物理世界模型分离**——知道水怎么流的人不做决策，做决策的人不知道水怎么流。临摹实测（6 轮 5.0→6.5 平台）暴露的四个病灶：① 无前向模型（盲下笔）；② 逆映射靠搜索不靠学习（反问题病态，收敛律锁死）；③ 回路货币是语言（用语言做几何，损失连续性）；④ 评价是带因果的层级价值不是标量（vision 是噪声裁判，可行动的只有因果诊断）。

一句话：**画家是"前向模型 + 逆技能 + 视觉运动回路"融于同一体的反馈控制系统；我们是三个分离部件加搜索补丁伪装成融合。** 工程补丁（场景图/三评委/keep-best）是多项式级的，病灶是结构级的。

出路假设（GPT 分析互补后修订）：**先验可画性 → 再学逆映射**——① 可画性（Oracle 1/2：平面笔触拟合 + 水彩控制频谱，验证动作基底与介质动力学可达目标，连最优求解器都画不出的东西怪 Agent 是怪错对象）；② 引擎蒸馏（Oracle 3：批量 rollout 训练可微代理 + "画面→下一笔"逆策略，把想象力装进决策者）；③ 过程先验与审美（Oracle 4：贝叶斯目标 p(P|I*) ∝ p(I*|P)·p_human(P)，评价对象是未来干画分布而非当前帧）。全文与证据见 `docs/reflection-painter-loop.md`。
