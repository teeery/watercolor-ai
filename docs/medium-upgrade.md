# 介质核心升级分析（medium-upgrade 分支）

> 范围：只动 `src/core/` + `src/paper/`（岸线/边带的渲染消费端仅一行读取缝，见 §B）。
> 方法：逐项对代码定位现状 → 病因 → 方案 → 验收。行号以分支创建时的源码为准。
> 配套：`docs/engine.md`「工件缺口 backlog」、`docs/engine-js.md`「已知问题」、`docs/architecture.md` 升级缝。

## 0. 结论先行

1. **四个任务里有三个共用一套底层机制**：岸线算子（B）的"边缘向内流 + 沿边沉积 + 边带噪声"同时是咖啡环、水洼成环、炸花 bloom、硬边强化、颜料分离雏形的引擎；各向异性纸纹（A）的方向场同时是毛边纤维爬行、方向颗粒、纸纹三档的前提。**先做 B 与 A，湿态 8 项能从 2/8 推到 6/8，干态从 3/8 推到 6/8，而不是一件件加特效。**
2. **bloom 圆瓣化（C）是全场最干净的升级缝**：形状生成（`Rθ`）与颜料搬运（质量守恒溅射）在 `pushPigmentRadial` 里已经解耦，换形状生成器即可，搬运一行不动。
3. **性能（D）应当最先做**：活跃集 + 静止短路是纯行为保持重构，让后面所有实验的迭代速度翻倍。
4. 盐花、硬边、纸纹三档、重力淌色是**廉价单件**，可穿插；湿中混色/分离/絮凝要等颜料属性库补字段，属 P2。

## 2. 四大任务分析

### A. 各向异性纸纹（纤维方向场）——治"圆形"的物理层那一半

**病因**：纸的四个场 H/C/G/F 全是各向同性 fBm（`paper.js` L22-34）；流场只有压力梯度 + 重力 + 无方向噪声（`engine.js` L317-330）；湿前沿扩张是纯 W 阈值（L361-371）——所以湿铺边缘天然圆润、颗粒全局均匀、飞白只有笔势一个方向。

**方案（分两步，先场后调制）**：

1. **方向场**（`paper.js`）：新增 `Tx/Ty`（纤维切向 cosθ/sinθ 数组）。θ 用单倍频低频 value noise + 平滑（`θ = valueNoise2D(x·0.012, y·0.012) · 2π`），再叠加纸预设的全局主方向偏置（hot-press 近零、rough 强）。同时给 H 加一个"沿纤维的条状起伏"分量：`H += a·fbm(x'·f1, y'·f2)`（x' 沿纤维、y' 跨纤维，f2 ≫ f1）——纸面物理纹理本身就带方向，后续一切调制都省一半力气。
2. **各向异性扩散**（`engine.js` L332-359）：kDiff 拆成沿纤维 kD∥ > 跨纤维 kD⊥，四邻域权重按该格 Tx/Ty 与邻格方向点积调制。水沿纤维走得远 → 湿铺边缘出现方向性毛边。
3. **流场耦合**（L317-330）：流速加一项 `u += (Tx·(u·T)) · kFib`——顺纤维流动放大、横纤维受阻。
4. **毛细爬行（湿态第 7 项）**：掩码扩张（L361-371）改两段：先阈值扩张（θ 不变），再补一趟"纤维爬行"——`W > 0.6θ` 且沿纤维方向紧邻格已湿 → 并入 M。前沿不再是等距圆弧，而是沿纤维咬出的毛边。
5. **沉积线断裂**：frontDeposit（L448-473）的 k 乘 `(0.5 + |Tx 与边缘法向点积|·0.5)`——前沿横跨纤维处沉积断档，纵跨处沉积加强 → 深边不再是连续描边（同治愈 vision 对天空/池塘的批评）。
6. **方向性飞白与颗粒**：`strokes.js` grainBreak 的条状噪声（L184-189）从纯笔势方向改为笔势 × 纸纤维的混合方向；`render.js` 颗粒层 F 采样点沿纤维方向拉伸（`F(x+s·Tx, y+s·Ty)` 混合）→ 颗粒聚成条而不是均匀椒盐。
7. **lift 默认方向**：`liftMask` 的 `dir` 未指定时取纸纤维方向（L136）。

**验收**（对应用户口径）：湿铺边缘不再圆润化——同一条 wet-wash，直方图化边缘法向应出现纤维方向峰值；`effects_p1_flat_wash` 视觉上边缘呈撕边/纤维毛边；颗粒在特写中呈条状聚簇。

**风险**：方向感过强会变成"木纹滤镜"。对策：幅度参数全部保守起步（kFib ≤ 0.15、方向噪声低频单倍频），用 effects 面板 A/B 收敛。

### B. 岸线交互（岸线算子）——枢纽任务

**病因**：真实岸线的结构是「水体 → 近岸透明带 → 深色水线 → 外侧浅线」。蒸发在边缘最快，内部水持续向边缘补给、把颜料一路运到水线沉积，透明带是被"搬空"的区域。现引擎缺的正是这段**持续向内补给流**：

- frontDeposit 只在掩码扩张那一刻钉一次线（静态）；
- 蒸发（L502-540）只是 `W *= (1−rate)` 原地减水，颜料原地冻结；
- 唯一的拉边（L514-536）是 k=0.12 的**一次性**邻格搬运，不累积。

所以池塘（`scene.js` L36-38）只有 blob 轮廓线，没有水线、没有透明带。vision 反复点名的正是这个结构缺失。

**方案（岸线算子，落在 `_stepOnce` 蒸发阶段之后）**：

1. 复用已有的 `_Mb = blur(M)`（L583-605）得到边带强度 `e = Mb − M` 与**向内的**梯度 `g = −∇Mb/|∇Mb|`。
2. 对边带内格（0 < e < eMax，约水线内侧 2-4 格）施加**只作用于颜料的**平流速度：`u_pig += shoreK · e · g`，shoreK 与当步蒸发率成正比（**蒸发驱动输送——因果耦合，known #4 的示范解**）。
3. 输送到边界格的水+颜料按比例沉积，且**跨步累积**——干燥 600 步下来，边带内颜料被逐步掏空（透明带自然出现），水线逐步加深（深色水线自然出现），外侧保留早先 frontDeposit 的浅线。
4. **水线噪声断裂**：沉积率乘沿岸切向的 1D 噪声 × 中频颗粒 G——水线断断续续、粗细不一，不再"描边"。
5. **granulation 分档**：岸线平流系数对 granulation 高的颜料打折（重颗粒走不动、留在透明带内沉淀）→ 颜料分离（湿态第 8 项）拿到零成本的雏形。

**一鱼四吃**：岸线算子 = 咖啡环强化 = 水洼干后成环 = 炸花 bloom（滴清水 → 由干燥前沿推进成环，而不是静态算子） = 分离雏形。这是本分支收益密度最高的单点。

**渲染缝**：渲染侧 edgeBand（`render.js` L35-38）目前是均匀暗边。岸线算子交付后，深边信息已存在 D 场里，render 的 edgeDarken 可下调为辅助项；若想更准，引擎侧新增 `edgeMask` 场供 render 乘用——一行消费，不算破坏 `core/` 边界。

**验收**：池塘特写（`crop_pond`）出现「深色水线 + 近岸透明带 + 外侧浅线」三层结构，vision 评分上升；`demo/analyze.js` 加岸线径向剖面探针（水线峰值 − 透明带谷值 ≥ 可测阈值）。

**风险**：输送过快会出现"挖空池塘"。对策：shoreK 默认值保守（≈ evap 的 1-2 倍量级），透明带宽度随干燥时长自然生长，不做显式清空。

### C. bloom 圆瓣化（曲率驱动前沿）——形状生成器换表

**病因**（`engine.js` L159-292）：`Rθ = radius·(1+0.42·(nA−0.5)·2)`，nA 是**角度域的 1D fbm**（L175-178）。1D 噪声函数在极小值处是 V 形尖谷 → 花瓣凹槽是尖的；极大值处也尖 → 瓣尖是尖的。解析增强段（L242-246）用同一 nA 再放大 0.5 幅度，把同样的尖谷再加深一遍。**星形是"把噪声当形状"的必然产物，不是参数问题。**

**方案（v2 形状生成器，搬运机制一行不动）**：

1. 前沿改为**半径剖面 R(θ)**（256 样本 Float32 环），用曲率驱动演化替代角度噪声：
   `R ← R + ΔR·(v0 + vc·(κ0 − κ(θ)) + vN·noise(θ)) + D·R''`
   - κ(θ) 是半径函数的曲率：`κ = (R² − R·R'' + 2R'²)/(R² + R'²)^{3/2}`；
   - `vc·(κ0 − κ)`：低曲率处（圆润段）加速生长、高曲率凹口停驻——这是菜花失稳的真实机制；
   - `D·R''`：曲率扩散项，把尖角抹圆——**圆润是构造保证的**；
   - noise 只做初始扰动种子（低频、小幅度），不再是形状本身。
2. 花瓣谷加**地板**：`R(θ) = max(R(θ), floor)`，凹口肥圆不尖（真实菜花花瓣谷也是圆沟）。
3. 三处使用 Rθ 的地方（搬运 L186、增强 L246、滴心稀释 L285）全部改为**查表**（角度线性插值、环回）——顺带省掉每格两次 fbm 调用。
4. 两朵雷同（known #2）：种子与半径各加 per-stroke 抖动；`re-wet` 协议加可选 `seed` 字段。
5. 滴心稀释判据 0.75·Rθ（L286）改为 0.75·R(θ) 的地板值以上——保证不切进肥花瓣。

**验收**：`crop_pond` 的 bloom 由星形瓣变圆润菜花瓣，vision 评分上升；`demo/ring-probe.js` 8 扇区径向剖面：凹槽处曲率半径显著增大（数值可测）；质量守恒不变（搬运路径未动，probe 复核总量差 ≤ 容差）。

**风险**：曲率演化参数（vc/vN/D）需要一轮调参；好在形状与搬运解耦，调参不动颜料。这是全场最干净的缝，可单独开实验。

### D. 性能（半拉格朗日 + 活跃集 + 静止短路）

**现状**：RGB 31 笔 ≈ 55-65s、光谱 ≈ 2.7×；干燥 600 步 3s。每步 bbox 全扫一遍 10 个阶段；光谱 17 通道 × 每格 bilerp。热区：颜料平流（L375-417）、全 bbox 循环本身（bbox 收敛后仍覆盖大半画布）、干燥期照常跑全套。

**方案（按收益排序，全部行为保持）**：

1. **活跃集（active cell list）**：维护湿格紧凑列表（Uint32Array + count），掩码扩张时增量 append、冻结时压缩。所有阶段改遍历活跃集——迭代成本 ∝ 湿格数而非 bbox 面积。31 笔场景典型收益 2-5×。
2. **静止短路（quiescence skip）**：每步若 `max|u| < ε` 且无新湿格（T 全 0）→ 跳过流场与两级平流，只跑沉积/蒸发/冻结。干燥期（600 步）变成 3 个廉价算子，3s → <1s；画面静置段同理。
3. **通道早期退出**：平流前先查一次 `solutionTotal(i)`（已有该函数），为 0 直接置零跳过 17 次 bilerp；沉积段已有 total 检查，保持。
4. **微优化**：`|u| < 0.5` 格平流退化为直接拷贝；`_T.fill(0)` 保留（成本已低）；bbox 收紧 30 步/次改事件驱动。
5. **阶段时钟**（可选）：平静区流场/平流每 2-3 步算一次，蒸发每步——CFL 在现参数下安全。
6. 光谱 16 波段保持；若仍需再压，考虑模拟 8 波段（相邻合并）+ 渲染 16 波段，但 K·d 映射要小心，**暂缓**。

**验收**：`demo/render-demo.js` RGB 全流程 ≤ 30s、光谱 ≤ 90s、干燥 ≤ 1s；**行为不变**——与基线 `out/compare.png` 像素差 ≤ 容差（活跃集/短路是纯重构，这是硬回归门槛）。新加 `demo/bench.js`（用现成 debugHook 分阶段计时）作为仪表。

## M0 执行记录（perf-m0 分支，已完成）

**交付物**：`engine.js` 活跃集重构（主列 + 孤儿列 + T-list + 延迟出列）、`quiescentU` 静止短路（opt-in，默认 0 = 行为保持）、`demo/bench.js`（分阶段仪表）、`demo/m0-probe.js`（场 dump/逐笔校验和/单格追踪）、`demo/png-diff.py`（像素回归工具）、`render-demo.js` 支持 `QUIESCENT_U` 环境变量。

**性能实测**（bench.js，RGB，32 笔 4975 步）：

| 模式 | paint sim | 其中 4-pigment | TOTAL |
|---|---|---|---|
| 基线（bbox 全扫） | 50.9s | 17.3s | 60.8s |
| M0 exact（活跃集，行为保持） | 46.3-51.1s | 16.8-17.9s | 56.1-61.3s |
| M0 + quiescentU=0.02 | **27.8s** | **4.8s** | **37.8s** |

诚实结论：**exact 模式收益只有 ~5%**——demo 场景的大面积湿铺让"湿格数 ≈ bbox 面积"，活跃集省不了主热区（4-pigment 的 bilerp 数量不变）；真正的杠杆是静止短路（平静期跳过流场+两级平流），paint sim −40%。剩余大头：笔触遮罩 6.9s（brush 层）与渲染 8.5s（color 层），非 M0 范围。**≤30s 目标未达成**（需再砍渲染/遮罩或换更小场景），已在上述数字基础上如实改写。

**行为保持验证**（quiescentU=0）：
- `demo_final.png`、`compare.png`、`effects_sheet.png` + 8 格面板：与基线**逐位一致**（mean=0, max=0）。
- 场景 32 笔逐笔场校验和：新旧引擎一致；色卡流程（24 颜料 × 2 笔 + 400 步干燥）终态 11 个场（含 Pm/Dm/ux/uy）：**逐格逐位一致**。
- 色卡 PNG 回归**撤回**：基线之后 `pigments.js/system.js/spectra.js` 被并行修改（非引擎因素），PNG 不可比；引擎级等价由场对比证明。

**静止短路代价**（quiescentU=0.02 vs exact）：mean 0.12/255、max 34/255、1.2% 像素 >1/255——集中在洗色边缘（平静期重力漂移被抑制）；vision 独立评审判"两张不可分辨，demo 可接受"，并建议后续加**滞回阈值**（防平静↔活跃频繁切换跳变）。

**精确性发现（M1-M5 必须复用的三条铁律）**：
1. **阶段 8（蒸发咖啡环拉取）是全场唯一跨格写依赖阶段**（对邻格 P 原地乘减，迭代顺序敏感）→ 必须保持 bbox 栅格序遍历，不能换活跃集。
2. **bbox 版的 stage 4 早退清零是隐式垃圾回收器**：干格残留的 ≤1e-6 溶液被下一阶段 4 顺带清零。活跃集版必须**延迟出列一格**（冻干后留列一步，让 stage 4 复刻那次清零），否则残量永久滞留。
3. **bbox 外的孤儿格**（lift 溢出的水）在 bbox 版里完全不参与模拟（冻结到尾部蒸发）→ 活跃集必须拆"孤儿列"单独搁置，并在 bbox 收紧/扩张时重新分流。

**遗留**：`uCopy` 阈值短路（|u| 小则免 bilerp）未做——静止短路后收益边际，且会叠加像素微差；留给光谱系统优化时一并评估。

## M1 执行记录（各向异性纸纹，已完成第一轮）

**方案修正**（依据 `docs/brush-dynamics.md` 附录 I 的 MoXi 2005 精读）：原方案"kD∥>kD⊥ 扩散张量 + 角度噪声"会退化成**木纹滤镜**——主机制换为 MoXi 四件：σ 钉扎、κ 变渗透率、阻滞、渐变固着；Tx/Ty 降为辅助。

**实现**（`src/core/engine.js` + `src/paper/paper.js` + `render.js` 一行）：

| 机制 | 落点 | 备注 |
|---|---|---|
| σ 钉扎 | `depositMask` 新湿格：局部水量 < σ(纸纹G+颜料密度+沿纤维线段噪声) → 前沿回退；钉扎格沿纤维邻格已湿 → 爬行润湿（toe/分支） | 毛边/锯齿前沿的成因；`_sigmaAt()` |
| κ 变渗透率 | 流场压力项 ×κ、扩散 ×κ；κ = 1+κg·(G−0.5)·2−κf·min(1,Dm·1.5) | 沉积堵塞反馈 → 分支纹 |
| 阻滞 | 颜料平流系数按 |u| 平滑打折、横纤维分量最强（每格预计算一次，不进通道循环） | 方向颗粒/沉积断裂的物理版 |
| 渐变固着 | 冻干格逐 step 固着 fixRate=0.5，固着完成（total≤0.02）后出列 | 替换二值冻结；"颜料随纤维滞留" |
| 容纸度 | 沉积 ×max(1−W/λ, m) | 浅边晕 |
| 纸坡 ∇H | 流场 +(−∇H·kSlope·wv)，替换 G 噪声扰动 | Montesdeoca 指针① |
| Tx/Ty 辅助 | 小量扩散各向异性（0.25）+ 流场沿纤维耦合（0.1） | 防木纹滤镜 |
| 渲染降权 | `render.js` edgeDarken 0.38→0.12 | 模拟侧边缘已生效，防"灰色铅笔线"（vision 终审意见） |

**验收（vision 独立评审）**：**7.5/10，较 bugfix 版 +0.5**。微观全部成立——蓝色六边形角部凸刺/缺口、绿弧内缘钉扎回退、树干左缘沿纤维向下爬行（"全图最成功的纤维证据"）、地面横向条状颗粒团簇；无木纹滤镜感。剩余扣分（面积更小、更易修）：宏观轮廓仍圆滑（缺大尺度撕口）、绿弧等宽环残留、边缘降权产生的"光晕环"、天-山/山-山白缝、树干缺口等距如梳齿、草笔扫描线感。

**性能**：M1 增量 = 热点阶段 +50~70%（同机同负载对比，并行会话拖慢绝对值）；`QUIESCENT_U=0.02` 仍有效（paint sim 72→40s）。后续优化候选：渐变固着滞留格数压缩、κ 预计算场。

**M1.1 候选**（vision 建议，收益序）：① 钉扎幅度叠加低频扰动 → 宏观撕口；② 环强度 = f(局部曲率, 干燥速度) 随机断环（绿弧问题）；③ 相邻色块接缝互渗/backrun 线替代白缝；④ 梳齿间距抖动 + 草笔单笔干扫；⑤ 颗粒沉积对比度提升（群青式条纹）。其中②③与 M2 岸线算子天然合并。
