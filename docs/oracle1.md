# Oracle 1：平面笔触拟合《乡村田野》

> 定位：`docs/reflection-painter-loop.md` 终局裁决的「第一块多米诺」——抽掉介质，只问「现有参数化笔触表示能否重建目标」。
> 一句话结论：**不能**。平面拟合在 **≈17.5 dB PSNR、vision ≈4–5/10 处低位平台**：骨架对、高频细节与清晰边界不可达。三分支落向「笔触表示/布局是硬约束，先补形状词汇」。判定性质：**候选成立**（不是铁证，见「诚实边界」）。

## 问题

《乡村田野》临摹卡在 vision 6.5 平台。五轮反思把责任分给三处：表示（笔触词汇）、介质（可控性）、求解（AI 策略）。Oracle 1 的第一刀：**完全不涉及水介质**，用同一套几何原语（rect/ellipse/poly/ribbon）去「平涂重建」参照——若平涂也平台在低位，锅在表示，不在水、不在 AI。

## 方法

- 平面渲染器 `src/paintability/flat.js`：soft 覆盖 mask + alpha-over 合成，纯参数化几何（无 fbm/纸纹/扩散——抖动是位置的确定函数，不是自由度）。
- 拟合器 `src/paintability/oracle1.js`：
  1. **粗到细贪心匹配追踪**：进度 t 让「尺寸带」从大塌缩到小（先大洗铺底、后小笔补细节，镜像五阶段作画制度）；残差最大处重要性采样落笔；按总残差能量选笔；插入时闭式最优色 → 误差单调不增。
  2. **颜色精修 `refineColors`**：平面合成对每笔颜色是**线性**的 → 固定几何/alpha 下是最小二乘 → 凸 → 坐标下降收敛到**全局最优色**（逐笔系数 = alpha·mask·后缀透射率）。这一步清零「贪心在颜色维度留下的余量」，是逼近 oracle 的关键一步。

## 数据

参照 1728×2304 → 480×640（引擎模拟网格同频上限，见 `docs/paintability.md` 嫌疑 4）。

| 预算 | greedy MSE | greedy PSNR | 精修后 MSE | 精修后 PSNR |
|---|---|---|---|---|
| 8 笔 | 0.0337 | 14.7 | 0.0330 | 14.8 |
| 160 笔 | 0.0272 | 15.7 | 0.0192 | 17.2 |
| 320 笔 | 0.0255 | 16.0 | 0.0172 | 17.6 |

- 误差曲线：1–3 笔快降（0.049→0.034），之后缓行；预算翻倍（160→320）只再降 ~0.47 dB → **硬地板，非预算限制**。
- vision 独立评审（dsh-sight）：构图 5/10、整体相似 **4–5/10**；天/田/房骨架保住，麦穗/树带/瓦线塌缩成「平均色」，边界全软、无连续轮廓 → 「失焦照片」。
- 对照：引擎水彩 83 笔 copy ≈6.5（人写笔序 + 介质纹理）> 平面拟合 ≈4–5。

## 裁决（三分支）

> `reflection-painter-loop.md` 终局：平面逼近成功 → 走 Oracle 2（介质）；平面低位平台 → 补笔触表示；平面像但难看 → 品味层。

**落点：平面低位平台 → 补笔触表示（形状词汇 / 硬边 / 纹理），而非进 Oracle 2。**

理由：
1. 颜色已全局最优（凸最小二乘），颜色维度无剩余空间 → 全部余量在**几何/布局**；
2. 预算翻倍只 +0.47 dB → 不是「笔不够」，是「这个表示在此分辨率下的可达域天花板」≈17.5 dB；
3. vision 定性：瓶颈是「形状与布局」（软边成片、无轮廓、无纹理），不是颜色。

## 诚实边界（为什么是「候选」不是「铁证」）

- 几何走的是贪心尺寸带，**不是真 oracle**——几何局部精修 / 硬边先验可能再挤 ~1–2 dB，但不改变「低位平台」的定性（17.5 与 19 都是低位）。
- 词汇缺 `spatter`（颗粒/麦穗纹理）与 `lift`（负形/留白减法）——这正是「补表示」清单的前两项。
- 颜色未约束到参照调色板，产生少量青/紫溢色（视觉伪影，非主线）。

## 复证（若要做铁证）

1. 几何精修（每笔局部搜索，或可微 autodiff 几何）→ 看真 oracle 下 floor 是否仍在 ~17–19 dB。
2. 补 `spatter` / `lift` / 硬边原语重跑 → 看「可达域天花板」是否被顶开。
3. 可画性十基元电池（`docs/paintability.md`）出第一版成绩卡——把「高频不可达」从这张画泛化到逐基元。
