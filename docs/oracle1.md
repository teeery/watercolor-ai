# Oracle 1：平面笔触拟合《乡村田野》

> 定位：`docs/reflection-painter-loop.md` 终局裁决的「第一块多米诺」——抽掉介质，只问「现有参数化笔触表示能否重建目标」。
> 一句话结论：**不能**。平面拟合在 **≈17–20 dB PSNR、vision ≈4–5/10 处低位平台**：骨架对、细节与锐边不可达。
> 判定性质：**强证据/工程终证**（六根独立杠杆都撬不动地板，且已把「频率上限」这一先前猜测**反证**掉——见「终证」）。

## 问题

《乡村田野》临摹卡在 vision 6.5 平台。五轮反思把责任分给三处：表示（笔触词汇）、介质（可控性）、求解（AI 策略）。Oracle 1 的第一刀：**完全不涉及水介质**，用同一套几何原语（rect/ellipse/poly/ribbon/spatter）去「平涂重建」参照——若平涂也平台在低位，锅在几何表示，不在水。

## 方法

- 平面渲染器 `src/paintability/flat.js`：soft 覆盖 mask + alpha-over 合成，纯参数化几何（无 fbm/纸纹/扩散——抖动是位置的确定函数，不是自由度）。
- 拟合器 `src/paintability/oracle1.js`：
  1. **粗到细贪心匹配追踪**：进度 t 让尺寸带从大塌缩到小；残差最大处重要性采样落笔；按总残差能量选笔；插入时闭式最优色。
  2. **颜色精修 `refineColors`**：平面合成对每笔颜色线性 → 凸最小二乘 → 全局最优色。
  3. **几何精修 `refineGeometry`**：细段每笔随机微扰、整图重渲染评估、保优（非凸局部下降）。
  4. **频率消融 `boxBlurRGB`**：把目标低通到网格尺度，测「抹平子网格纹理后表示能否吃下可分辨结构」。

## 数据

参照 1728×2304 → 480×640（引擎模拟网格同频）。

| 预算 | greedy PSNR | 精修后 PSNR |
|---|---|---|
| 8 笔 | 14.7 | 14.8 |
| 160 笔 | 15.7 | **17.2** |
| 320 笔 | 16.0 | **17.6** |

- vision 独立评审（dsh-sight）：构图 5/10、整体相似 **4–5/10**；天空/田野/房屋骨架保住，麦穗/树带/瓦线塌缩成「平均色」，边界全软无轮廓 →「失焦照片」。
- 对照：引擎水彩 83 笔 copy ≈6.5（人写笔序 + 介质纹理）> 平面拟合 ≈4–5。

## 终证（六杠杆撬地板）

把「候选」升级到「工程终证」的对照实验，全部 160 笔 + 颜色精修：

| 杠杆 | 变化 | 地板移动 |
|---|---|---|
| 颜色 | greedy → 全局最优色（凸 LSQ） | **+1.5 dB**（15.7→17.2，唯一有分量） |
| 预算 | 160 → 320 笔 | +0.47 dB |
| 词汇 | +spatter 颗粒原语 | +0.18 dB |
| 词汇 | +细段硬边（soft↓） | −0.09 dB |
| 求解 | 逐笔几何局部搜索 | +0.15 dB |
| 不透明度/硬边 | opaque + hard（硬轮廓不透明笔） | −0.5 dB |

### 频率消融（反证「频率上限」猜测）

把目标 box-blur 到网格尺度再拟合（`demo/oracle1-freq.js`）：

| blur r | fitPSNR（拟合 vs 抹平目标）| gapPSNR（原图 vs 抹平目标）|
|---|---|---|
| 0 | 17.32 | ∞ |
| 1 | 18.47 | 26.24 |
| 2 | 18.89 | 24.19 |
| 3 | **19.79** | 23.14 |
| 4 | 19.51 | 22.42 |

判读（MSE 直接比较，r=2）：拟合离原图 0.0185，其中「拟合 vs 网格尺度抹平目标」0.0129 占大头，「抹平目标 vs 原图（=子网格纹理）」0.0038 次要。**抹掉子网格纹理只能把天花板抬到 ~19.8 dB，而抹平目标本身离原图 22–26 dB——所以地板不是奈奎斯特/频率上限，是「网格尺度的重建失败」。** 先前「补表示 = 提分辨率/频率上限」的判断被此实验**证伪**。

### 硬边+不透明测试

抹平目标(r=2)下：软笔 18.89 / 硬边 18.65 / 硬边+不透明 18.36 dB——**锐利不透明原子在手，贪心也没用来追轮廓，天花板不动。** → 排除「软剪影/低不透明度」是主因。

## 裁决（三分支，处方修正）

> `reflection-painter-loop.md` 终局：平面逼近成功 → Oracle 2；平面低位平台 → 补笔触表示；平面像但难看 → 品味层。

**落点：平面低位平台 → 补笔触表示。** 处方在终证后**精确化**：

- **不是**频率/Nyquist（已反证）、不是再添原语、不是不透明度/硬边、不是预算（六杠杆证死）。
- **是**「平滑原子 × 贪心匹配」在网格尺度的**卡通/低通分段天花板**：贪心把图逼近成低通分段，无法系统性追踪多尺度锐利轮廓与区域内差异；残差大头 0.013 MSE 集中在网格尺度的边界/结构，而非子网格纹理（0.004）。
- **补什么**：方向性锐边原子（step/ridge/curvelet 类）或**纹理残差通道**——后者正是**水彩介质通道**（纸纹/颗粒/水花/fbm），即引擎已有而平涂刻意抽掉的那块。引擎 6.5 vs 平涂 4.5 的那 2 分，预览的就是这条残差通道的贡献。几何天花板 ≈17–19 dB 是介质之下的硬地板，介质负责高频残差。

**对主线的影响**：Oracle 1 不阻断走向「介质/纹理」路线——它确立了「几何达地板、余量归介质纹理」这个清晰分工，并直接把 **十基元电池**（`docs/paintability.md`）指向「逐基元量化各原语对低/高频的贡献」。

## 诚实边界（为什么是「工程终证」不是「数学铁证」）

- 求解器仍非真 oracle：几何精修是弱局部搜索；完全可微 autodiff / 进化在 1600+ 维几何上不可行（全渲染 0.7s/次）。但**剂量-响应**已把余量钉死：六根杠杆除颜色(+1.5)、频率(+2.5)外全部 <0.5 dB，趋势强指向「真 oracle 也停在 17–20 dB 低位」。
- 颜色未约束调色板，产生青/紫溢色与矩形硬切边（视觉伪影，非主线）。
- 单张参照；逐基元正交测量是十基元电池的下一步。
