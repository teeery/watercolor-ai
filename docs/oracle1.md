# Oracle 1：平面笔触拟合《乡村田野》

> 定位：`docs/reflection-painter-loop.md` 终局裁决的「第一块多米诺」——抽掉介质，只问「现有参数化笔触表示能否重建目标」。
> 一句话结论：**不能**。平面拟合在 **≈17.3 dB PSNR、vision ≈4–5/10 处低位平台**：骨架对、高频细节与清晰边界不可达。
> 判定性质：**强证据**（四个独立杠杆都撬不动地板，见「复证」）——不是数学铁证，但已把「贪心弱」「缺词汇」「笔不够」「颜色没准」四条怀疑逐一排空。

## 问题

《乡村田野》临摹卡在 vision 6.5 平台。五轮反思把责任分给三处：表示（笔触词汇）、介质（可控性）、求解（AI 策略）。Oracle 1 的第一刀：**完全不涉及水介质**，用同一套几何原语（rect/ellipse/poly/ribbon/spatter）去「平涂重建」参照——若平涂也平台在低位，锅在表示，不在水、不在 AI。

## 方法

- 平面渲染器 `src/paintability/flat.js`：soft 覆盖 mask + alpha-over 合成，纯参数化几何（无 fbm/纸纹/扩散——抖动是位置的确定函数，不是自由度）。
- 拟合器 `src/paintability/oracle1.js`：
  1. **粗到细贪心匹配追踪**：进度 t 让「尺寸带」从大塌缩到小（先大洗铺底、后小笔补细节，镜像五阶段作画制度）；残差最大处重要性采样落笔；按总残差能量选笔；插入时闭式最优色 → 误差单调不增。
  2. **颜色精修 `refineColors`**：平面合成对每笔颜色是**线性**的 → 固定几何/alpha 下是最小二乘 → 凸 → 坐标下降收敛到**全局最优色**（逐笔系数 = alpha·mask·后缀透射率）。
  3. **几何精修 `refineGeometry`**：对细段每笔做 kPerturb 次随机微扰、整图重渲染评估、保优——非凸局部下降，逼近「贪心几何的局部最优」。

## 数据

参照 1728×2304 → 480×640（引擎模拟网格同频上限，见 `docs/paintability.md` 嫌疑 4）。

| 预算 | greedy PSNR | 精修后 PSNR |
|---|---|---|
| 8 笔 | 14.7 | 14.8 |
| 160 笔 | 15.7 | **17.2** |
| 320 笔 | 16.0 | **17.6** |

- 误差曲线：1–3 笔快降（0.049→0.034），之后缓行；预算翻倍（160→320）只再降 ~0.47 dB → **硬地板，非预算限制**。
- vision 独立评审（dsh-sight）：构图 5/10、整体相似 **4–5/10**；天/田/房骨架保住，麦穗/树带/瓦线塌缩成「平均色」，边界全软、无连续轮廓 → 「失焦照片」。
- 对照：引擎水彩 83 笔 copy ≈6.5（人写笔序 + 介质纹理）> 平面拟合 ≈4–5。

## 复证（四杠杆撬地板）

把「候选」升级为「强证据」的对照实验，全部 160 笔 + 颜色精修：

| 杠杆 | 变化 | 地板移动 |
|---|---|---|
| 颜色 | greedy → 全局最优色（凸 LSQ） | **+1.5 dB**（15.7→17.2，唯一有分量的一根） |
| 预算 | 160 → 320 笔 | +0.47 dB |
| 词汇 | +spatter 颗粒原语 | +0.18 dB |
| 词汇 | +细段硬边（soft↓） | −0.09 dB |
| 求解 | 逐笔几何局部搜索 | +0.15 dB |

- 四臂词汇消融（160 笔 refined PSNR）：baseline 17.16 / 锐化 17.07 / spatter 17.34 / spatter+锐化 17.32 → **添加「缺失」的颗粒与硬边原语，地板纹丝不动**。
- 几何精修：greedy 15.61 → 几何局部搜索 15.74 → 颜色精修 17.31（对照无几何 17.16）→ **局部搜索几乎不改贪心几何，+0.15 dB**。

## 裁决（三分支）

> `reflection-painter-loop.md` 终局：平面逼近成功 → 走 Oracle 2（介质）；平面低位平台 → 补笔触表示；平面像但难看 → 品味层。

**落点：平面低位平台 → 补笔触表示（可达域/频率上限），而非进 Oracle 2。**

理由：
1. 颜色已全局最优（凸 LSQ）→ 颜色维度无剩余空间，余量全在**几何/频率**；
2. 预算、词汇、几何三条杠杆都 < 0.5 dB → 地板 ≈17.3 dB 是**可达域天花板**，不是「笔不够/缺词汇/贪心弱」；
3. vision 定性：瓶颈是「形状与频率」（软边成片、无轮廓、无纹理），不是颜色。

**补什么（细化的处方）**：残余误差集中在麦穗/瓦线/草丛这类高频纹理——与 `docs/paintability.md` 嫌疑 4（频率上限）一致。候选机制是 **480×640 模拟网格的奈奎斯特上限**：纹理存在于网格尺度之下的频率，任何平滑覆盖原语在此分辨率都渲不出来。因此「补表示」不是再添一个喷射原语，而是**提高有效分辨率 / 加高分辨局部瓦片通道**（`docs/paintability.md` 嫌疑 2/4 的方向），或承认此分辨率的平涂重建到此为止、把高频交给更高频通道（Z 的细节级）。

## 诚实边界（为什么是「强证据」不是「数学铁证」）

- 几何精修是**弱局部搜索**（4 扰 × ±6px、只细段、一轮），真 oracle（可微 autodiff / 进化）理论上可能再挤 1–2 dB——但三根杠杆的边际收益（<0.5 dB）趋势强指向「即便再挤也在 17–19 dB 的低位」，不改分支。
- 颜色未约束到参照调色板，产生少量青/紫溢色与矩形硬切边（视觉伪影，非主线，见 vision 复核）。
- 只测了「这一张参照图」——十基元电池（`docs/paintability.md`）是把「高频不可达」从单张泛化到逐基元正交测量的下一步。
