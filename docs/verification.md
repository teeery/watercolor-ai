# 人工验收手册（DSH 自治成果如何用肉眼/命令复核）

> 自治循环的问题：机器报一堆数字、改一堆文件，人没法确认它"真做了"还是"编的"。本手册把每一轮 claim 都落到**可复现的命令 + 期望输出 + 可打开的图片**上。你不需要读代码，按下面三件事做就能复核。

## 前置（一次）

- 环境：Node ≥ 18（本项目 v24 下验证），无第三方依赖。
- 参照图：`out/copy-ref/乡村田野.png` **仅本地**（不入库）。没有它，`npm run oracle1` 会退出码 1 并提示——这是设计行为。若你本地没有，先自行放一张命名一致的原图，或只看「复现数字」之外的进度（当前结论不依赖这张特定的图，见 `docs/oracle1.md`「诚实边界」）。
- 产物目录 `out/` 被 git 忽略——**图片/报表是跑命令后才生成的**，不是仓库里躺着的文件。

## 三件事

### ① 复现数字：一条命令，看到和我报的一样的数

在仓库根目录：

```bash
npm run oracle1          # 平面拟合 160 笔（约 50 秒）
```

期望在标准输出末尾看到（±0.1 dB 属同一结果，浮点/PNG 顺序确定）：

```
[oracle1] strokes=160 greedy=15.61dB -> refined=17.2dB elapsed=~50s
```

这就是我多轮反复引用的「地板 ≈17.2 dB」的出处。**你看到 15.6 → 17.2，就证明：(a) 工具链真的在跑；(b) 颜色精修真在起作用；(c) 数字不是我编的。**

频率消融（本轮"频率上限被反证"的结论）：

```bash
npm run oracle1:freq    # 五档抹平 + 拟合（约 4.5 分钟）
```

期望末尾表：

| blur r | fitPSNR | gapPSNR(原图-抹平) |
|---|---|---|
| 0 | ~17.32 | ∞ |
| 2 | ~18.89 | ~24.19 |
| 3 | ~19.79 | ~23.14 |
| 4 | ~19.51 | ~22.42 |

**判读**（一句话）：抹平子网格纹理只能把拟合抬到 ~19.8 dB、且抹平目标本身离原图还有 22–26 dB → 地板不是"分辨率/Nyquist 上限"，是"网格尺度的重建失败"。

硬边+不透明对照（约 2 分钟，无图输出）：

```bash
node demo/oracle1-hardtest.js
# soft ~18.89 / hard+opaque ~18.36 / hard-only ~18.65  → 硬边不透明也撬不动
```

### ② 肉眼看图：打开 `out/oracle1/` 里的这张

跑完 ① 后，用图片查看器打开：

- `out/oracle1/montage.png` —— 三栏：**参照原画 | 平面拟合 | 引擎水彩 copy**。你要验收的核心结论就是"中栏失焦、只剩平均色、无清晰轮廓"——肉眼即可确认与 docs 里 line「4–5/10、失焦照片」一致。
- `out/oracle1/flat_final.png` —— 放大看的拟合终稿（2×）。
- `out/oracle1/curve.png` —— MSE 随笔数先快降后平台，即"低位平台"的形状。
- `out/oracle1/freq_r0.png` / `freq_r2.png` —— 抹平目标 | 其拟合，佐证"抹平后依然糊"。
- `out/oracle1/report.json` —— 本次跑的配置与分项数字（脚本里 `rec` 对象原样落盘）。

### ④ 十基元电池（本轮：随机贪心 ≠ oracle 的负面结果）

```bash
node demo/paintability/battery.js   # 约 2.5 分钟
```

期望输出末尾——**8 个基元形状区 PSNR 都偏低（7~20 dB），且每行标注「求解下界（非可达域裁决）」**，并有一句 `⚠ 判读：…` 说明这些数字不是引擎可达域结论。

肉眼复核：打开 `out/paintability/1_line.png`（目标 | 拟合 | 误差热图三栏）——你能直接看到中栏**连五条直线都没画对**（斜线漏、竖线灰、粗细没重现、误差线全红）。这就是本轮最重要的结论：**随机贪心不是 oracle，它连自己能表示的直线都搜不到**；所以这些低 PSNR 是「求解器弱」的证据，不是「引擎不可达」的证据。详见 `chronicle/08-可画性十基元电池v0.1.md`。

## 常见疑问

- **数字对不上？** 先确认参照图一致（其它图会给出不同绝对 dB，但"15→17、抹平只抬到 19"的**相对形状**不变）；同图同命令时差值应在 0.05 dB 内。
- **`out/` 里是空的？** 因为它是 gitignored 的运行时产物，先跑 ① 的命令才生成。
- **没 push 你 remote 看不到？** 对，按你的决定我**只本地 commit**。要同步就说「推」。
- **为什么结论"改口"过（频率上限→卡通天花板）？** 那是诚实迭代：频率消融的数据反驳了我上一轮的自猜，我把旧结论在 `docs/oracle1.md`／README 里**显式更正**了，没有掩盖。验收时可在 `git log -p` 里看到更正轨迹。
