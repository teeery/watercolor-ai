# dsh-studio 实战教训（本项目的需求输入）

## 做了什么

SVG 白名单 + sharp 光栅化 + vision 自评 + keep-best 3 轮循环 + gallery + 进化 GIF。两幅 demo：浮世绘鲸鱼（18→18→23/25）、水彩榕树女孩（19→19→未评，VLM 限流）。过程诚实，输出平庸。

## 教训清单 → 本项目的对应决策

1. **白名单锁死质感**（禁 filter → 无水痕/毛边/颗粒）→ 介质交给引擎，模型只画形状。本项目根基。
2. **评分维度缺失**：rubric 五维全是技术正确性，满分也平庸 → 新 rubric 加 `aesthetics`（光感/情绪/介质真实度）；批评模板要求点出"最丑的一块"与"最动人的一块"。
3. **批评粒度与执行粒度不匹配**（主题级反馈 vs 路径级执行）→ stroke 级批评 + 局部撤笔。
4. **单候选 + 整幅重生成**：好零件保不住（水彩 R2 修了主体掉了构图）→ 多候选（局部 3 选 1）+ 增量笔画。
5. **"30 秒动图"实为 9 秒**（3 帧轮播）→ 真实干燥时间线，时长即真实作画时长。
6. **LLM 手写 SVG 细节错误率高**（连渐变方向都会错）→ stroke JSON 是结构化协议，引擎负责视觉正确性。
7. **免费 VLM 限流直接断环** → provider 可配、重试、显式降级。
8. **预设埋在 SKILL.md，加风格要改代码** → 颜料/纸参数数据化，风格 = 参数预设文件。
9. **成品没进会话**（用户要手动开文件）→ Phase 2 挂 attachments。
10. **人物题材翻车重灾区**（VLM 两画都点 anatomy）→ 引擎尖峰先用风景/静物验证；人物留到笔触品味成熟后。
