# 接入层：agent 笔序 + vision 阶段批评

（Phase 1；先让引擎尖峰通过，再接这一层。）

> 协议与架构：stroke 协议 v0.2（`brush`/`motion`/颜料名优先）见 `docs/engine.md`；能力层与目录落点见 `docs/architecture.md`。

## 画一张画的流程（阶段制）

1. **构图**：agent 规划笔序（先湿后干、由浅入深），产出 stroke 计划。
2. **铺色**：大面积湿铺（天空、树冠、地面），引擎渲染 → vision 看真实画布。
3. **湿画**：趁湿叠色、滴清水制造回流开花；批评聚焦"该湿的地方湿了没、水痕是否失控"。
4. **干画**：干皴细节、毛边、点景；批评聚焦局部（"这儿的回流糊了""这块留白被吃了"）。
5. **收尾**：观察全局，必要时 `lift` 洗色、`spatter` 溅点，定终稿。

## 批评粒度升级（对 dsh-studio 的直接解药）

- dsh-studio 教训：批评是主题级（"缺背鳍"），执行是路径级 → 命中率低。
- 这里：**批评对象是一笔或一个局部**。"撤掉第 14 笔"比"重画整幅"便宜一万倍——stroke 级修改天然支持局部修正与多候选（同一局部 3 笔变体，vision 选 1）。

## 复用的架构遗产（dsh-studio）

- 循环骨架：阶段预算、总笔数硬上限、keep-best、会话日志即证据链。
- 诚实守则：不伪造批评；限流/异常时显式降级（暂时人工代评，如实标注）。
- 交付物：final PNG（8K 重渲染）、evolution 动图（真实时间线，不再是帧轮播）、gallery 页（阶段快照 + 批评原文 + stroke 源码）。

## 成本模型（预估）

- 每阶段 1-2 次 vision 调用；总笔数 40-80；总耗时分钟级。
- 免费 VLM 限流 → provider 可配 + 重试 + 降级路径（dsh-studio demo 已实锤此风险）。
