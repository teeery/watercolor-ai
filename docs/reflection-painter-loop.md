# 反思小论文：水彩绘画系统的病灶推演与出路裁决

> 性质：问题记录 + 多轮推演的完整存档。本文档按**推演进化的方式**记录事实、判读、互补、修正与裁决，不隐藏任何一轮的错判与被推翻的结论。
> 缘起：临摹《乡村田野》实测（6 轮 vision 闭环：5.0 → 5.5 → 6.0 → 6.2 → 6.5，逐轮收益 +0.2~0.5 递减，平台期出现）。
> 参与者：本会话（判读/裁决）、GPT 独立诊断（两轮互补）。
> 定位：后续开发与研究的指导文件；每一条结论都标注了它在推演链中的位置与被修正的历史。

## 第〇轮 · 事实基础（问题记录）

1. **平台期是真实的**：同一套"画→vision 批→改笔"闭环，第一轮涨 0.5，第四轮后降到 +0.2，稳定在 6.5 附近。批评质量没有变差（每轮指认都准），是**收益在收敛**。
2. **vision 是噪声标量**：同一幅画三轮独立评审给出 7.0 / 8.2 / 8.8。但每轮的**因果诊断稳定且可用**——真正驱动改进的是"晕来自双层随机偏移"这种话，不是分数。
3. **决策盲区产生真错误**：果实 `layers:2` 的双层随机偏移造成"错版晕"——画家在心里模拟过就绝不会犯的错，我犯了，因为下笔 90 秒后才能看到结果。**知道水怎么流的人不做决策，做决策的人不知道水怎么流。**
4. **坐标是模型的先天弱势**：协议逼 LLM 把空间直觉（"云在房左上一掌"）翻译成绝对坐标（`cx:170, cy:224`）。人画画用锚点与相对关系，不用坐标。
5. **纹理信息密度是词汇量瓶颈**：临摹差在瓦缝、麦芒、云形、石墙砌缝这类"结构细节沿对象生长"的笔法——介质物理（湿扩散/颗粒/干边）全部 convincingly 在场，差在笔画粒度。

同时，对"导师式系统建议"（场景图/三评委/候选搜索/keep-best/局部回滚）做了批判性阅读：**它在工程上几乎全对，但是症状清单**——闭环慢就加搜索、几何差就加场景图、评审噪就加评委。它没有回答：为什么这个系统需要这么多补丁？补丁是多项式级的，病灶是结构级的。

### 附：导师式系统建议要点存档（推演起点之一，供对照）

该建议的正确成分后来被逐条吸收进 Oracle 序列与处方，特此存档，避免"事后诸葛亮"式的遗忘：

- **系统闭环与定位**：视觉理解（分区/轮廓/深度/光色）→ 绘画蓝图（场景图/图层/留白/遮挡）→ 笔序规划（湿铺→塑形→干画→收尾）→ 生成下一小组候选笔触 → 引擎试画 → 结构/审美/介质三方评审 → 定位错误到区域、对象、具体笔触 → 撤笔/换笔/调水/局部重画 → 冻结阶段进入下一层 → 高分辨率确定性重放。定位为**"模型预测控制"**：AI 不一次写完整幅画，每次只规划未来几笔、试画候选、看结果再决定。
- **双路线拆分**：忠实临摹模式（精确画幅坐标映射/轮廓比例遮挡/大色块明暗/局部颜色纹理/笔触服从原图结构）与艺术创作模式（构图重组/主次/色彩和谐/边缘节奏/适度省略/风格一致）**不能共用一个模糊目标**；最终用"忠实↔表现"滑杆选择后验条件。
- **层级场景表示**：全局（画幅/地平线/焦点/光源/主色调）→ 大区（天空/远景/主体/地面/前景）→ 对象（房屋/树/石墙/麦田/花草）→ 子结构（屋顶/山墙/窗/瓦片/草叶/麦穗）→ 视觉属性（轮廓/颜色/明度/边缘软硬/纹理方向）。每个对象至少保存：精确掩膜、可见轮廓、遮挡与被遮挡关系、平均色与内部梯度、明暗层级、保留纸白区域、适用技法、允许/禁止扩散边界、目标细节等级。**其中"遮挡关系"最重要——没有它，房屋像漂浮纸盒，树墙田不形成空间。**
- **笔画两级表示**：语义技法层（平涂/渐变洗/湿画湿/罩染/负形塑造/提色/干笔/勾线/点叶/点景/留白/擦洗修正）→ 物理笔刷层（笔型宽度方向/路径曲率/速度压力倾斜/起行收笔/笔腹笔尖颜料量/水与颜料沿路径衰减/脏笔吸色混色回蘸/纸面湿度反馈）。**"不要让 AI 在数百个底层参数里盲猜，它应该说'用偏干的小号圆笔，沿麦穗生长方向提锋'，系统再编译成物理参数。"**
- **五阶段作画制度**：① 构图骨架——只画 5-10 个最大色块，**关闭水彩物理用平面诊断渲染器**验证主体位置/地平线/比例/正负形，"这一阶段都不像，绝不能进入水彩模拟"；② 大色调与空气感——天空地面远景，只评审整体；③ 主体塑形——逐对象，独立掩膜与局部画布，可撤销重画比较候选；④ 结构性细节——瓦片窗框麦穗草叶**沿对象结构生长**，细节预算自适应（屋顶可能上百笔，天空几次大洗），"不能人为把复杂画限制为 83 笔"；⑤ 艺术性收尾——焦点强化/非焦点弱化/边缘软硬/局部提亮压暗/飞白溅点，"水彩味主要在这一阶段锦上添花，不能用它遮盖结构错误"。
- **三方独立评审 + 可执行定位格式**：结构评审（对象检测/IoU/轮廓距离/关键点透视/明暗层级/色差/多尺度感知相似度）、审美评审（视觉中心/主次/平衡/色彩统一/疏密虚实/笔触经济性/机械重复检测）、介质评审（湿干边是否合笔序/颗粒是否服从纸纹/回流湿度窗口/罩染透明层次/干笔方向/数字噪声条纹泄漏）。**每次批评必须输出可执行定位**："错误对象：主屋屋顶；错误类型：轮廓与透视；位置：x=45%–72%, y=39%–51%；原因：右坡过宽，屋脊方向错误；建议：撤销第 61–68 笔，生成三个新屋顶候选"——不能只说"房子不够像"。
- **候选搜索制度**：重要动作生成 3-8 个候选（路径/笔宽/水量/配方/软硬/密度），低分辨率副本试画、三方联合评分、keep-best；配阶段预算、硬性笔数上限、局部回滚、确定性随机种子、完整笔触日志、任意阶段重放。
- **引擎升级清单（十条）**：修正旧干笔长短轴方向错误；对象掩膜/裁剪组/遮挡层；水掩膜与颜料掩膜区分；局部干燥状态；确定性逐笔撤销与重放；前景细节迁移新笔刷动力学；细线在干纸阶段保持不被数千步扩散破坏；纸张/颜料/笔刷实测校准集；模拟分辨率与输出分辨率解耦；重要局部高分辨率瓦片模拟。
- **学习路线九步**：规则与专家知识基线 → 视觉闭环与候选搜索 → 收集真实过程数据 → 学习人类笔序与局部决策 → 训练审美偏好模型 → 最后才用强化学习优化长期笔序。**"最有价值的数据不是'原图—成品'图片对，而是过程数据……只有成品图，模型学到的是外观；拥有过程轨迹，模型才能学会画画。"**
- **四里程碑**：① 结构像（修干笔方向/20-50 张固定临摹基准/参考图分区轮廓颜色提取/场景图与遮挡/平面诊断渲染器/"平面版先准确，再接入水彩物理"）；② 会纠错（逐笔日志/阶段快照/结构评审/错误定位/候选试画 keep-best 局部回滚/"从一次生成 83 笔改成每次规划 3-10 笔"）；③ 像真实水彩（迁移新笔刷/校准/修扩散与细节保存矛盾/介质真实性测试集/真实水彩扫描件盲评）；④ 极其好看（专家排序与修改记录/审美偏好模型/风格档案/省略与强调的学习/"第 100 张作品明显优于第 1 张"）。
- **战略取舍**：**"最稀缺的不是盐花、颗粒或新颜料，而是三样东西：结构化的眼睛、可回滚的笔序、能定位错误的评审闭环。如果只能做一项：建立'参考图 → 分层场景图 → 平面试画 → 结构评审 → 局部重画'的闭环。"**

## 第一轮 · 四病灶判读（本会话）

### 根 1：决策者与物理世界模型分离——系统没有"想象力"

画家下笔前知道会发生什么：这是多年经验压缩出的**前向模型**，"这笔下去边缘会积线"在下笔前就预演过了。人画画几乎不用试错，画是"想"出来的。

我们的架构把这条链切成三段：LLM（没有水的模型）→ 引擎（有水的模型，只执行）→ vision（事后裁判）。**知道水的不会决策，做决策的不知道水。**

这正是 `docs/paradigm.md` "三权分立"设计的暗面：分工解决了"模型伪造介质"，代价是决策盲区。出路不是放弃分工，是给决策者配一个蒸馏出来的前向模型。

### 根 2：临摹是反问题，而逆映射靠搜索不靠学习

画家的技能是学出来的**逆映射**：(当前画面状态, 意图) → 下一笔，由几十年正演经验训练而成。

临摹要解的是更狠的反问题：把引擎倒过来——给定 2D 目标，反推笔序。这是**病态的**：层叠顺序、水量、时间轴全部在 2D 投影里丢失。人类用先验补全丢失维度；我们用黑箱试错硬搜。**只要逆映射靠搜，收敛律不变**（+0.2~0.5/轮）。候选搜索与 keep-best 只是把试错并行化。

### 根 3：回路的货币是语言，绘画是视觉运动域

人在连续视觉拓扑空间里思考；我们的回路每一跳都在翻译：图像→文本→坐标 JSON→图像→文本。每次翻译损失连续性——"屋脊高 12 像素偏左 8 像素"这种信息在翻译中不存在。**我在用语言做几何。**

### 根 4：评价是带因果的层级价值，不是标量

画家的真实技能是**此刻该服从哪个目标**：这一步忠实、那一步美感、下一步介质真实——三者不可通约，不能加权求和。评分是噪声标量；可行动的永远是因果诊断。

### 一句话病灶

> **画家是一个"前向模型 + 逆技能 + 视觉运动回路"融合在同一个体里的反馈控制系统；我们造的是三个分离部件（文本规划器 / 黑箱物理 / 噪声裁判），然后用搜索与补丁伪装成融合。**

### 首版处方

把引擎正演知识蒸馏进决策者：批量 rollout 训练可微代理 + "当前画面→下一笔"逆策略。廉价验证：临摹池塘子任务尖峰，看 6 轮平台期是否被打破。

## 第二轮 · GPT 独立诊断的互补增量

> 判定：与第一轮互补。其中"根 0"把病灶往前推了一个前提；四 Oracle 把验证升级为科学诊断。

### 增量 1：根 0——可画性（可控性）从未被验证

第一轮四根默认了一个前提："介质引擎+动作基底足以产生目标图像"。这个前提可能为假。系统只有正演 `x_{t+1}=F(x_t,a_t), I_t=G(x_t)`，从未回答：**动作空间与介质动力学能稳定实现哪些形状、边缘、频率、颜色与透明层次？**

- 笔刷只能产生圆斑与断裂印章 → 连续草叶不可达；扩散消灭某尺度以下结构 → 瓦线不可达；动作只能加颜料而提色有限 → 早期错误不可恢复；**480×640 的介质网格决定可控空间频率上限**。
- 判据：正交基元基准（直线/曲线/尖叶/三角/T 接/封闭轮廓/硬软边/渐变/罩染层/条纹频率/负形留白提色/湿画湿边界/干燥保真度），用最优求解器找最低"目标—干画"误差。**若连最优求解器都画不出尖叶，问题在引擎与动作基底，不在 Agent。**
- 灵敏度分析 `J=∂φ(I_dry)/∂a` 奇异值 → "水彩控制频谱"（低频大色块可控、中频轮廓部分可控、高频草叶瓦线可能不可控）。
- 这把事实 5（纹理密度词汇量瓶颈）从"工程描述"升级为**可证伪的介质命题**。

### 增量 2：逆问题正式形式化 + 过程不可辨识

绘画问题的正确目标不是"最小化终稿误差"，而是：

`a* = argmax [ −D(G(F^T(x0,a)), I*) + λ·log p_artist(a|I*,s) − μ·C(a) − ν·R(a) ]`

四项：终稿相似度 + **过程先验**（像不像画家会做的事）+ 复杂度成本 + 不可逆失误/失控风险。

**过程不可辨识**：同一终稿可由无数程序产生（一百笔自然笔触 / 一万笔像素补丁 / 大色块加噪 / 纸色遮盖 / 优化器攻击）。只评终稿相似，优化器必然找到"看着像但过程荒谬"的捷径。正确目标是贝叶斯后验：

`p(P|I*,s,m) ∝ p(I*|P,m) · p_human(P|s,m)`

第一项保证像，第二项保证过程像画家——与"过程真实"范式同源，但写成了目标函数。推论：**必须学习绘画过程先验；最有价值的数据是过程轨迹，不是成品图对。**（文献：ProcessPainter）

研究史注：模型式绘画代理这条线已经局部碰到过这个问题——可微神经渲染器提供动作梯度（Learning to Paint）；笔触生成被直接重写为参数搜索，并发现**普通像素损失存在零梯度和参数耦合问题**（Stylized Neural Painting）。但这些工作多数处理的是可微、不透明的笔触叠加，**还没有真正解决水彩这种有隐藏状态、延迟干燥和不可逆历史依赖的介质**——这恰是本文档要攻的空白。

### 增量 3：评价对象是未来干画分布，不是当前画面

水彩的隐藏状态 + 延迟反馈意味着：批评当前湿画可能**惩罚一笔干后会变正确的动作**。策略应优化：

`E[ D(I_dry^{t+h}, I*) | x_t, a_{t:t+h} ]`

这更接近带延迟反馈的随机模型预测控制，而不是"画一笔、截屏、让 VLM 说两句"。

### 增量 4：可绘制表征 Z

场景图（对象分割）只解决语义，不解决绘画。画家操作的中间量是：明度块、冷暖、正负形、边缘归属、透明色层、留白拓扑、笔势方向场、视觉重心、局部对比、湿干时序。建议"可绘制表征"：

`Z = { V 明度场, L 透明色层与顺序, E 边缘场, O 遮挡拓扑, T 笔触方向场, Q 纸白负形约束, S 视觉显著性, M 建议技法 }`

对一幅原作，系统做的是"逆水彩分解"——推断这块结果由哪几层洗色、哪次留白、哪种湿度、哪些干笔形成——与"识别这是房子"不是同一个问题。

### 增量 5：审美是生成性先验，不是错误检测

评审器善于指出不平衡/乱/不像/对比不足，但**不能可靠地产出决定性的非局部选择**（整体压暗前景？牺牲忠实强化主体？哪条边最硬？删掉原作中真实但破坏画面的细节？）。需要"艺术构想模型"在作画前产出：视觉命题、焦点叙事、保留与偏离清单、明暗压缩、色彩组织、笔触密度地图、边缘节奏、完成判据。"极其像"与"极其美"是**不同的后验推断条件**（忠实/表现滑杆）。

### 增量 6：四 Oracle 误差解剖

`E_total = E_representation + E_medium + E_inverse + E_taste`

| Oracle | 问题 | 暴露病灶 |
|---|---|---|
| 1 平面笔触 | 不考虑水彩物理，现有笔触基底能否重建目标（可微平面渲染器自动拟合） | 表示能力缺口 |
| 2 水彩控制 | 理想优化器控制现有引擎能否达标 | 介质可控性缺口 |
| 3 AI 策略 | 已知存在好解时 AI 能否找到 | 策略与学习缺口 |
| 4 审美 | 画得像但不好看 | 过程/审美先验缺口 |

对《乡村田野》的实验顺序：① 平面笔触拟合——不像 → 笔触表示不足（补形状词汇）；② 平面像、进水彩引擎后不像 → 介质不可控或细节带宽不足；③ 存在好程序但 AI 找不到 → 才轮到 Agent（蒸馏尖峰在此）；④ 像但不好看 → 才轮到先验与审美。**这修正了第一轮的处方顺序：蒸馏尖峰（Oracle 3）之前必须先跑 Oracle 1/2。**
（文献：Learning to Paint / Stylized Neural Painting / DiffVG / CVPR 2026 双参数化笔触规划）

### 增量 7：LLM 不直接握笔——五段分工

语言 token 是低带宽、离散、缺乏空间精度的控制通道。分工：**LLM = 艺术总监**（题材/风格策略/技法解释/是否重规划）；**绘画策略模型 = 熟练画家**（基于目标表征+介质状态+过程先验提出下一组动作）；**连续优化器 = 手眼协调**（微调曲线/宽度/压力/水量/颜色/时机）；**正向引擎 = 真实世界**；**未来状态预测器 = 经验**（预估干后结果与失控风险）。

研究史注：可微绘画研究正在从"纯离散搜索"与"纯连续梯度"两端向**双重表示**靠拢——因为离散搜索容易陷入局部最优，纯可微优化又容易得到缺乏结构的笔触；CVPR 2026 的双参数化笔触规划正好印证了这个矛盾（离散/连续两端各有缺陷，中间态才是出路）。

## 第三轮 · 深入反思（本会话，含对第一轮的自修正）

> 主题：把上一轮的结论也放上手术台，包括自己的四个根。以下每条都改变了下一步决策。

### 修正 A："画家"隐喻的拆解——求解器不必像人

"造一个像画家的系统"把两件不同的事混成了一件：**解必须像人**（`p_human(P)` 约束绘画程序的层序、干湿时序、笔法语法——这是产品的一部分）；**求解器不必像人**（棋引擎从不想棋手一样思考，靠搜索+评估碾压，但产出的对局完全人类可读）。

我们的系统逼 LLM 当画家（逐笔文本、无物理记忆、开环盲下笔）。根 1-3 咬人的原因不是"LLM 不够像画家"，而是**求解器被钉死在画家的形态上**。出路不是让 LLM 更像人，而是让求解器自由使用机器的强项（精确状态、重放、批量、梯度），只约束解的**人类合理性**。

→ 由此修正根 2 的表述：不是"从搜索换成学习"，而是——**问题从来不是搜索本身（机器天生会搜），是求解器没有前向模型可搜。** 棋引擎 = 搜索 + 学出来的评估函数。我们要的：**学出来的前向代理 + 逆策略引导的搜索。**

### 修正 B：过程真实的粒度——层/时间线级，而非笔触级

观者真正感知的"过程"是一层层罩染的顺序、湿接湿的时机、干后才有的水痕——**可见的过程语法**，不是笔的微观运动。"一万笔像素补丁"捷径被拒不是因为笔多，是因为可见语法错了。

推论：过程先验的学习目标应定义在**层/时间线粒度**，而非笔触粒度。这直接决定蒸馏什么、学习目标的可达性（后者容易得多）。这是一个**待盲测验证**的假设（"层序正确但笔法怪" vs "笔法正确但层序怪"，观者更在意哪个？）。

### 修正 C：可画性按"程序可达域"量，不按原语量

用正交基元测"介质能不能画尖叶"有误区：画尖叶未必需要尖叶原语——**负空间**可以（把叶间背景画出来，叶自然成形）。留白是原作的呼吸孔，纸白通过"不画"天然可达。Oracle 1/2 的正确量法是**端到端程序级可达域**，否则会把"规划器不会表示负形"误判成"介质画不了"。

### 修正 D："LLM 管意图"里的"意图"从未被定义

stroke JSON 不是意图，是执行。真正的意图是 **Z（可绘制表征）**。LLM 的真实价值在 Z 层（语义、强调与省略、色彩组织），学出来的策略模型管实现（在这个介质里如何达到 Z）。**LLM 与策略模型之间的接口应该是 Z，不是笔触。**

### 发现 E：品味数据飞轮——开发即数据采集

`docs/taste.md` 说"品味是数据，人是唯一神谕"。**临摹迭代本身就是品味数据**：每一轮 = 专家在某个画面状态下做了什么决定的样本（改哪几笔、为什么、下一版怎么走）。vision 因果诊断 + 人的裁决 + 执行 = 编辑轨迹，比成品图对金贵。推论：开发流程应被仪器化——每轮迭代的（画面前、改动笔集、画面后、批评理由、是否采纳）存成结构化数据。

### 发现 F：研究线与产品线是同一资产

产品护城河是"过程可见"，研究线是"逆向水彩理论"。两者收敛到同一件东西：**一个能逆向自己介质的引擎**。产品的时间线重放 = 正向引擎；研究的逆合成 = 反向能力。不是"先产品还是先研究"的取舍，是同一资产的两种变现。里程碑应按"哪个实验既推进理论又产出可见能力"来排——Oracle 序列恰好全部满足。

### 挑战 G：GPT"LLM 不该握笔"的绝对化反对

作为原则同意，作为绝对论断反对。问题不在语言本身，在**接口带宽与域**：把画布以低分辨率图像放进模型上下文、用学出来的空间 token 定位，LLM 完全可能胜任策略模型。真正的铁律是：**不要让空间控制经过数字 token 化（`cx:170` 这种），让模型留在图像域里思考。**

### 裁决 H：第一个实验的裁决

所有讨论收敛到一个可证伪的问题：**《乡村田野》的 6.5 平台，是表示吃掉的、介质吃掉的、还是求解吃掉的？** 可微平面拟合（Oracle 1）是第一块多米诺：平面笔触能逼近原作 → 表示够用，瓶颈在介质或求解；平面也平台在低位 → 笔触词汇量是硬约束。无论结果如何都改变我们对系统的理解。

## 第四轮 · GPT 对处方的三处关键修正 + 第五根

> 判定："已经非常接近真正病灶。尤其前三根不是优化建议，而是在指出系统的认识论结构有问题。"但"训练代理模型 + 下一笔策略"仍可能在更高水平上重演现在的问题。

### 对第一轮四根的逐项判断（GPT）

| 第一轮的根 | 结论 | 需要再钉死的地方 |
|---|---|---|
| 决策者与物理分离 | 命中核心 | 不要求代码上合并，但必须在功能上成为**可快速反事实查询的内部世界模型** |
| 没有逆映射 | 命中核心 | 逆映射不是单值函数，而是**带风格与过程先验的条件分布** |
| 语言承担视觉运动货币 | 命中核心 | 正确货币不只是像素，而是**连续空间特征 + 隐藏介质状态** |
| 评价是因果层级价值 | 判断正确 | 这一根**不会被代理模型自然治愈**，需要独立的目标调度机制 |

### 修正 1（对根 1）：不是普通前向模型，是"反事实能力"

部件是否物理分离不关键（飞机控制器与空气动力学模型也是独立模块）；关键在于控制器能否快速询问："如果现在加第二层会怎样？如果等到半干再画？水量减 30% 干后边缘在哪？如果这笔失败还有恢复路径吗？" 引擎目前是只能执行真实动作的世界，不是可以反复想象的世界。

缺失的是 `p(x_{t+h}, I_{t+h}^dry | x_t, a_{t:t+h})`，必须：足够快（允许一次决策预演大量未来）、预测多时间尺度（刚落笔/半干/全干）、输出不确定性、支持反事实干预、能对动作求梯度或提供高质量方向。

`layers:2` 是诊断范例：真正的内部模型应在落笔前比较 `I_dry(layers=2) − I_dry(layers=1)` 并发现错版风险。**注意：普通神经代理不会天然产生因果诊断——必须用随机化干预数据训练，显式保留 layers/含水量/湿度/纸张/时间等因果变量。**

### 修正 2（对根 2）：学习的是"解的分布"，不是逆函数

下一笔通常没有唯一答案（可以先画屋顶也可以先压远景；可以一笔宽洗也可以三笔叠加；两种笔序都可能得到相似终稿但只有一种符合画家习惯）。用回归损失训练 `a_t = f(I_t, I*)` 会把多个正确动作平均成不存在的"折中笔触"。正确形式：

`a_t ~ q_φ(a_t | z_t, z*, g_t, s)`（多模态，提出几种合理动作而非输出均值）

搜索与学习不是二选一：**学习把大范围盲搜摊销成高质量动作先验，短视野模型预测搜索处理当前画布的特殊情况**（过去经验=第一反应；世界模型=心里预演；小范围规划=临场调整）。

### 修正 3（对根 3）：不能简单改成"让模型看像素"

水彩是**部分可观测系统**：两张看起来几乎相同的画布可能一张很湿一张近干、一张颜料悬浮一张已沉积、一张可湿接一张会出硬边、一张色浅因水多一张色浅因颜料少。只用 `当前RGB+笔触→下一张RGB` 训练会遇到**状态混叠**。

正确状态：`z_t = E(I_t, W_t, P_t, D_t, H, brush reservoir, history)`。语言保留但只用于高层意图（"现在进入干画阶段，重点服从屋顶结构，禁止破坏天空留白"），不再负责把"屋顶不对"翻译成几十个坐标。

### 修正 4（对根 4）：价值调度不会被蒸馏世界模型自动解决

世界模型能说"这笔下去会产生硬边"，但不能自行决定"此刻该追求硬边，还是牺牲结构准确保持空气感"。加权和 `r = w1·r忠实 + w2·r美感 + w3·r介质` 允许严重结构错误被漂亮纹理"抵消"。正确形式是**层级约束 / 词典序决策**：

```
subject to  C_topology ≤ ε1,  C_reserved-white ≤ ε2      // 先满足不可破坏约束：留白、拓扑、主体比例
then         minimize  D_stage-goal                      // 在可行解里保证当前阶段目标（如主体结构）
then         maximize  A_style/process                   // 再优化笔触自然与水彩美感
finally      minimize  笔数与效率                        // 最后考虑成本
```

**价值不是永恒标量，而是随阶段和因果状态变化的控制模式。**

### 第五根：我们把"一整笔"错误地当成原子动作

真实画家在笔内也持续感知调整（出水快提速、边缘扩散减水、笔腹干加压、偏离改向、收笔提锋）。真实结构不是"观察→决定整笔→执行→再观察"，而是"观察→微动作→感知介质响应→微动作→…→收笔"。"笔触"应是带内部反馈的技能，不是不可中断的动作。

分层：高层策略（画一片尖叶）→ 技能策略（方向与意图）→ 微控制器（每几个模拟步输出位置增量/速度/压力/倾斜/出水量）→ 世界模型（持续预测未来响应）→ 终止器（何时收笔）。

### 处方总装（GPT 版）

> 建立一个以隐藏介质状态为条件、预测未来干画的视觉运动世界模型，并在其上训练多模态逆技能策略；策略提出动作，世界模型做短视野反事实规划，微控制器在一笔内部闭环执行。LLM 只负责艺术意图与目标切换。

三个耦合模型：**世界模型** `F̂_θ(z_t,a_t,Δt) → p(z_{t+Δt}, I^dry_{t+h})`；**逆动作提议器** `q_φ(a_t|z_t,z*,g_t,s)`；**价值与可恢复性模型** `V_ψ(z_t,z*,g_t)`（不只预测终稿分数，还判断偏差是否可恢复、动作是否封死未来解空间、是否应等待干燥、是否应停止本阶段）。

### 训练数据改写

"几百万组笔触—前后差"是必要起点，但单步随机 rollout 不够。必须记录：完整隐藏状态 W/P/D、笔刷水库与颜料状态、动作参数与随机种子、即时/半干/全干三个未来、连续多笔相互作用、同一状态下的参数干预对照、失败后是否可恢复、目标条件下哪些动作有用。

数据生成策略：正交实验覆盖基础动作 → 不确定性驱动主动采样 → 专门采样湿接/叠色/提色等高非线性区域 → 用当前策略制造它最常进入的状态 → 让优化器生成近优轨迹再蒸馏给逆策略 → 后续加入人类画家过程轨迹作为先验。**这是"搜索产生老师，学习摊销搜索，在线规划纠正学习"的循环。**

### 验证设计

不立刻做完整风景。选 20-30 个基础目标（渐变/尖叶/屋顶/软硬边组合），对照四种系统：① 语言规划器直接输出笔触；② 无世界模型的逆策略；③ 只有世界模型的 MPC 搜索；④ 世界模型 + 逆策略先验 + 笔内闭环。测量：同等误差所需真实引擎调用次数、首笔与前十笔有效率、灾难性不可恢复动作比例、预测干画与真实干画的校准误差、新纸/新颜料/新目标泛化、是否产生自然非投机的笔序。

**研究假设成立的标志：第四种系统在极少真实试错下就能作出正确动作，并能在落笔前预测错误及其原因。**

### 最终警告

> 不要把"可微代理 + 下一笔网络"再次做成两个新黑箱。它们必须围绕同一个隐藏状态、同一个视觉运动表征和同一套反事实接口共同生长——这样才是融合，而不是把原来的三段式系统换成另一组三段式系统。

更完整的画家模型：**反事实世界模型 + 多模态过程先验 + 层级价值调度 + 笔内闭环运动控制 + 对未来干画的预测。**

### GPT 对第一轮处方的最终修正句（原句存档）

> "你的四根诊断，前三根非常坚实，第四根也成立。我只会修正一句话：不是简单地'把正演知识蒸馏进 LLM'，而是建立一个与视觉运动策略共同训练、能表示隐藏介质状态、预测未来干画、支持反事实查询的内部世界模型；LLM 只负责艺术意图和目标切换。"

## 第五轮 · 终局裁决（本会话对第四轮的讨论）

### 对三个修正的接受与补刀

1. **接受修正 1，补刀**：我们有一个所有 MBRL 实验室都没有的便宜——引擎的真实隐藏状态（W/P/D/M/湿度）在训练时**免费可得**。世界模型不需要从像素里"涌现"latent，而是 **state→state 监督学习**，latent 被真实物理量锚定。这同时回应了"别造两个新黑箱"的警告：黑箱风险来自 latent 无约束；我们的 latent 天生有物理含义。
2. **接受修正 2，补刀**："学习摊销搜索"的循环与我们的处境精确对应——现在每次迭代都是人肉优化器在搜索，而搜索的过程数据（编辑轨迹）已经在免费生产。**开发即数据采集**从隐喻变成工程事实。
3. **接受修正 3，补刀**：直接推出一个**协议原则**——因果变量必须是一等公民。凡是影响结果的随机量（seed、偏移、水量扰动）必须显式暴露在协议里，否则再好的世界模型也无从反事实。

### 对第五根的排序异议

命题对，但**次级**：① 它治的是"盖章感"，不是临摹平台（《乡村田野》卡在屋顶结构/墙的落地/云形——规划与表示问题）；② 并行会话的 brush v2.0（水库/毛层/interleave/湿衰减）已在做"技能策略+笔内时间维"，不构成新战线。但有一条真增量接受：**微控制器可以直接骑在引擎的 60Hz 步进时钟上**——引擎天然是笔内时钟，比"预计算轨迹+interleave"更彻底。

### 对层级价值的诚实保留

词典序没有消灭品味问题，只是**挪了位置**：ε 阈值设多少、哪条约束"不可破坏"、阶段目标怎么排，依然要人来给；V_ψ 同样吃品味数据。正确表述：**层级价值调度把品味从"每次决策时的临场直觉"转化为"可积累、可复用的调度规则"**——这正是 taste.md 的落点。两笔账分开记：世界模型 = 物理（硬边会不会封死湿接），价值模型 = 品味（此刻该不该接受封死）。

### 融合的工程定义

> 世界模型、逆策略、价值模型、微控制器、乃至 LLM 的视觉上下文，必须读写**同一个状态表示、同一个反事实接口**。那个共享接口就是引擎状态本身。

可落地的前提已经存在：引擎状态真实可读（训练时）、引擎位级确定（M0 成果——干预对照数据的基础设施免费就有）。**融合不是训练一个更大的模型，而是把引擎状态升格为系统总线**。谁不接这条总线，谁就是新的分离部件。

### 验证的头条指标

GPT 的四系统对照设计正确（系统 1 就是现在的我们，基线零成本）。加一条头条指标：**在"临摹池塘"子任务上打破 6 轮、+0.2~0.5/轮的平台期**——这条有实测基线，输赢直接可判读。GPT 列的过程指标（引擎调用效率/首笔有效率/不可恢复动作比例/干画校准误差）作为解释性指标保留。

## 终局 · 收敛后的判读

### 病灶（认识论结构 + 表示粒度）

1. 决策者无反事实能力——控制者不知道世界如何演化，世界模型不能参与决策；
2. 逆解是分布而非函数——且当前靠搜索硬解，收敛律被锁死；
3. 视觉运动信息被迫经过语言窄道——数字 token 化丢失空间连续性，状态混叠丢失隐藏介质状态；
4. 价值是层级调度而非标量——加权和允许结构错误被纹理抵消；
5. （前提性）可画性未验证——动作基底与介质动力学的程序级可达域未知；
6. （表示粒度）笔非原子——缺笔内闭环与终止器。

### 处方（修正版）

> 以引擎真实状态为总线，训练"状态锚定的多尺度反事实世界模型 + 多模态逆策略 + 可恢复性价值模型"；LLM 只管艺术意图 g_t 与风格（接口是 Z，不是笔触）；微控制器骑在引擎步进时钟上做笔内闭环；过程先验定义在层/时间线粒度。**搜索产生老师，学习摊销搜索，在线规划纠正学习。**

### 下一步（不变的第一块多米诺）

**Oracle 1：可微平面笔触拟合《乡村田野》**——一切投资去向都取决于"表示够不够"的答案。结果三分支：平面逼近成功 → 瓶颈在介质或求解，走 Oracle 2；平面也平台在低位 → 笔触词汇量是硬约束，先补表示；平面像但整体不好看 → 问题在品味层。
