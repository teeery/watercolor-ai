# 问题记录与反思：为什么临摹平台期在 6.5，而不是继续涨

> 触发：临摹《乡村田野》实测（6 轮 vision 闭环：5.0 → 5.5 → 6.0 → 6.2 → 6.5，逐轮收益 +0.2~0.5 递减）+ 对"导师式系统建议"的批判性阅读。
> 性质：问题记录 + 结构性病灶诊断 + 研究假设。范式层面并入 `docs/paradigm.md`。

## 一、问题记录（实测事实）

1. **平台期是真实的**：同一套"画→vision 批→改笔"闭环，第一轮能涨 0.5，第四轮之后降到 +0.2，并稳定在 6.5 附近。批评质量没有变差（每轮指认都准），是**收益在收敛**。
2. **vision 是噪声标量**：同一幅画三轮独立评审给出 7.0 / 8.2 / 8.8。但每轮的**因果诊断稳定且可用**——真正驱动改进的从来是"晕来自双层随机偏移"这种话，不是分数。
3. **决策盲区产生真错误**：v4 果实 `layers:2` 的双层随机偏移造成"错版晕"——画家在心里模拟过就绝不会犯的错，我犯了，因为下笔 90 秒后才能看到结果。**知道水怎么流的人不做决策，做决策的人不知道水怎么流。**
4. **坐标是模型的先天弱势**：整条协议逼 LLM 把空间直觉（"云在房左上一掌"）翻译成绝对坐标（`cx:170, cy:224`），每笔都在做它最不擅长的换算；人画画不用坐标，用锚点与相对关系。
5. **纹理信息密度是词汇量瓶颈**：临摹差在瓦缝、麦芒、云形、石墙砌缝这类"结构细节沿对象生长"的笔法——不是介质物理（湿扩散/颗粒/干边全部 convincingly 在场），是笔画粒度。

## 二、对"导师式建议"的批判（工程优化 vs 病灶）

那篇建议的清单（场景图/三评委/候选搜索/keep-best/局部回滚/笔刷语义层）**在工程上几乎全对**，但它是**症状清单**：闭环慢→加候选搜索、几何差→加场景图、评审噪→加三个评委。

它没有回答：**为什么这个系统需要这么多补丁？** 补丁是多项式级的，病灶是结构级的——所以按它的路线走，会渐进收敛到另一个平台（我们刚亲眼见到一个），而不会质变。

## 三、四个结构性病灶（根源）

### 根 1：决策者与物理世界模型分离——系统没有"想象力"

画家下笔前知道会发生什么：这是多年经验压缩出的**前向模型**，"这笔下去边缘会积线"在下笔前就预演过了。人画画几乎不用试错，画是"想"出来的。

我们的架构把这条链切成三段：LLM（没有水的模型）→ 引擎（有水的模型，只执行）→ vision（事后裁判）。**知道水的不会决策，做决策的不知道水。**

这正是 `docs/paradigm.md` "三权分立"设计的暗面：分工解决了"模型伪造介质"，代价是决策盲区。出路不是放弃分工，是给决策者配一个蒸馏出来的前向模型。

### 根 2：临摹是反问题，而逆映射靠搜索不靠学习

画家的技能本质是学出来的**逆映射**：(当前画面状态, 意图) → 下一笔，由几十年正演经验训练而成。

临摹要解的是更狠的反问题：把引擎倒过来——给定 2D 目标，反推笔序。这是**病态的**：层叠顺序、水量、时间轴全部在 2D 投影里丢失。人类用先验补全丢失维度；我们用黑箱试错硬搜。**只要逆映射靠搜，收敛律不变**（+0.2~0.5/轮）。候选搜索与 keep-best 只是把试错并行化。

### 根 3：回路的货币是语言，绘画是视觉运动域

人在连续视觉拓扑空间里思考（形状、邻接、遮挡、方向）；我们的回路每一跳都在翻译：图像→文本→坐标 JSON→图像→文本。每次翻译损失连续性——"屋脊高 12 像素偏左 8 像素"这种信息在翻译中不存在。vision 给一段话，我把话算回坐标，**用语言做几何**。

正确方向：让模型在图像域内思考——画布以像素形式存在于模型上下文，文本只是标注。

### 根 4：评价是带因果的层级价值，不是标量

画家的真实技能不是"知道好不好"，是**此刻该服从哪个目标**：这一步忠实、那一步美感、下一步介质真实——三者不可通约，不能加权求和。评分只是噪声标量（见记录 2）；可行动的永远是因果诊断（"这个硬边是因为纸干了才叠第二层"）。

三个独立评审者各给分再加权，没有解决价值层级问题。需要的是决策时刻的目标选择，它来自对因果的理解，而非评分。

## 四、一句话病灶

> **画家是一个"前向模型 + 逆技能 + 视觉运动回路"融合在同一个体里的反馈控制系统；我们造的是三个分离部件（文本规划器 / 黑箱物理 / 噪声裁判），然后用搜索与补丁伪装成融合。** 且这个诊断成立的前提——动作基底与介质动力学的**可画性（可达域）**——从未被验证过。

## 五、研究假设与廉价验证

**如果只做一件事**：把引擎的正演知识蒸馏进决策者——用引擎批量生成几百万组（笔触, 画面前后差），训练一个快速可微的代理模型 + 一个"当前画面→下一笔"的逆策略。

这一步同时治四个根：给 LLM 装上想象力（根 1）、把反演从搜索变成学习（根 2）、让回路跑在毫秒级（反馈控制的前提）、并天然产出因果诊断（根 4 的原料）。

**廉价检验**：取"临摹池塘"一个子任务，做代理模型 + 逆策略尖峰，看 6 轮平台期是否被打破。

- 打破 → 判读成立，逆映射从搜索转向学习是质变的钥匙。
- 未打破 → 病灶判断需要再挖，回到根 2 的反问题病态性本身。

**但执行顺序已按 GPT 增量修订**（见下节 Oracle 解剖）：蒸馏尖峰属于 Oracle 3/4，必须先跑 Oracle 1/2——否则尖峰失败时分不清是"AI 找不到解"还是"介质根本不可达"。

## 六、对现有架构的连带裁决

- 场景图、三评委、keep-best、候选搜索：**保留，但降级为脚手架**——它们让系统"可用"，不解决"会画"。
- `docs/architecture.md` 能力层里的"眼睛层（vision 批评）"需要升级为**量化批评 + 因果诊断**双层：像素指标做定位（根 3 的连续性），vision 做语义终审（根 4 的因果）。
- 笔刷动力学 v2（并行会话）解决的是"笔内时间维"，与本文档的四根不冲突、是正课；但**不优先于蒸馏尖峰**。
- 优先级裁决：引擎蒸馏尖峰 > 参考图形状提取（B 类工程补丁）> 更多介质特效。

## 七、GPT 分析的互补增量（已并入判读）

> 来源：独立诊断（GPT）与本文档四根互补。以下六条是**新增信息**，不是重复：其中"根 0"把病灶往前推了一个前提，Oracle 解剖把验证升级为科学诊断。

### 增量 1：根 0——可画性（可控性）从未被验证

本文档四根默认了一个前提："介质引擎+动作基底足以产生目标图像"。这个前提可能为假。当前系统拥有的只是正演模型 `x_{t+1}=F(x_t,a_t), I_t=G(x_t)`，能回答"给定这一笔，纸面会发生什么"，但从未回答：**动作空间与介质动力学能稳定实现哪些形状、边缘、频率、颜色与透明层次？**

- 若笔刷只能产生圆斑与断裂印章，连续草叶不可达；扩散消灭某尺度以下结构，瓦线不可达；动作只能加颜料而提色有限，早期错误不可恢复；网格分辨率决定可控空间频率上限。
- 这是控制论的"可控性"问题，水彩语境下可称"可画性/介质可达域"。
- **判据**：一组正交基元基准（不同方向宽度直线、曲线、尖叶收锋、三角/T 接/封闭轮廓、硬软边、渐变、罩染层、条纹频率、负形留白提色、湿画湿受控边界、干燥保真度），用最优求解器找最低"目标—干画"误差。**若连最优求解器都画不出尖叶，问题在引擎与动作基底，不在 Agent。**
- 灵敏度分析 `J=∂φ(I_dry)/∂a` 的奇异值 → "水彩控制频谱"（低频大色块可控、中频轮廓部分可控、高频草叶/瓦线可能不可控）。
- 这把我方证据 5（纹理密度词汇量瓶颈）从"工程描述"升级为**可证伪的介质命题**。

### 增量 2：逆问题的正式形式化 + 过程不可辨识（精化根 2）

绘画问题的正确形式不是"最小化终稿误差"，而是：

`a* = argmax [ −D(G(F^T(x0,a)), I*) + λ·log p_artist(a|I*,s) − μ·C(a) − ν·R(a) ]`

四项：终稿相似度 + **过程先验**（像不像画家会做的事）+ 复杂度成本 + 不可逆失误/失控风险。当前系统只有 F、G，笔序是手写猜的，vision 批评循环本质是"用语言模型在巨大、连续、非线性、延迟反馈的动作空间里盲搜"。

**过程不可辨识**是第二理论病灶：同一终稿可由无数程序产生（一百笔自然笔触 / 一万笔像素补丁 / 大色块加噪 / 纸色遮盖 / 优化器攻击）。只评终稿相似，优化器必然找到"看着像但过程荒谬"的捷径。正确目标是贝叶斯后验：

`p(P|I*,s,m) ∝ p(I*|P,m) · p_human(P|s,m)`

——第一项保证像，第二项保证过程像画家。这与本项目的"过程真实"范式（paradigm.md）同源，但把它写成了目标函数。推论：**必须学习绘画过程先验，最有价值的数据是过程轨迹（每笔参数/湿度/阶段画面/为什么改笔/为什么停笔），不是成品图对。** 文献：ProcessPainter（终态生成无法还原真实创作过程）。

### 增量 3：评价对象是未来干画分布，不是当前画面（精化根 1 的修法）

水彩的隐藏状态 + 延迟反馈意味着：批评当前湿画可能**惩罚一笔干后会变正确的动作**。策略应优化：

`E[ D(I_dry^{t+h}, I*) | x_t, a_{t:t+h} ]`

蒸馏出来的前向模型必须预测**未来干态**（并携带不确定性），而不是预测当前帧。这更接近带延迟反馈的随机模型预测控制，而不是"画一笔、截屏、让 VLM 说两句"。

### 增量 4：可绘制表征（精化根 3 的修法）

场景图（天空/房屋/树/麦田的对象分割）只解决语义，不解决绘画。画家操作的中间量是：明度块、冷暖关系、正负形、边缘归属、透明色层、留白拓扑、笔势方向场、视觉重心、局部对比、湿边干边时序。建议建立"可绘制表征" Z = { V 明度场, L 透明色层与顺序, E 边缘场(软硬+归属), O 遮挡拓扑, T 笔触方向场, Q 纸白负形约束, S 视觉显著性, M 建议技法 }。对一幅原作，系统做的是"逆水彩分解"——推断这块结果由哪几层洗色、哪次留白、哪种湿度、哪些干笔形成——这与"识别这是房子"不是同一个问题。

### 增量 5：审美是生成性先验，不是错误检测（精化根 4 的修法）

评审器善于指出不平衡/乱/不像/对比不足，但**不能可靠地产出决定性的非局部选择**（整体压暗前景？牺牲忠实强化主体？天空更空？哪条边最硬？删掉原作中真实但破坏画面的细节？）。需要一个"艺术构想模型"，作画前先产出：视觉命题、焦点与叙事、允许保留与偏离的清单、明暗压缩方案、色彩组织、笔触密度地图、边缘节奏、完成判据。"极其像"与"极其美"不是一条损失上的两个分数，而是**不同的后验推断条件**——忠实临摹加大参考图似然权重，艺术创作加大过程先验与审美先验权重（对应"忠实/表现滑杆"）。

### 增量 6：四 Oracle 误差解剖（把验证升级为科学诊断）

总误差此前被混在一起，应分解为：

`E_total = E_representation + E_medium + E_inverse + E_taste`

| Oracle | 要回答的问题 | 暴露的病灶 |
|---|---|---|
| 1 平面笔触 Oracle | 不考虑水彩物理，现有笔触基底能否重建目标（用可微平面渲染器自动拟合原图） | 表示能力缺口 |
| 2 水彩控制 Oracle | 用理想优化器控制现有引擎能否达到目标 | 介质可控性缺口 |
| 3 AI 策略 Oracle | 已知存在好解时 AI 能否找到它 | 策略与学习缺口 |
| 4 审美 Oracle | 画得像但不好看 | 过程先验/审美先验缺口 |

对《乡村田野》的实验顺序：① 平面笔触拟合原图——不像 → 笔触表示无法表达目标（补形状词汇）；② 平面版像、进水彩引擎后不像 → 介质不可控或细节带宽不足（补引擎/分辨率）；③ 存在能画得像的水彩程序但 AI 找不到 → 才轮到 Agent（蒸馏尖峰在此）；④ 画得像但不好看 → 才轮到过程先验与审美。**这修正了本文档第五节的执行顺序：蒸馏尖峰（Oracle 3）之前必须先跑 Oracle 1/2。**

文献锚点：可微神经渲染器给动作梯度（Learning to Paint）；笔触生成改写为参数搜索、像素损失存在零梯度与参数耦合（Stylized Neural Painting）；曲线参数直连图像损失的 DiffVG；离散搜索与纯连续梯度各自缺陷、双参数化笔触规划（CVPR 2026）——正反两端的中间态。

### 增量 7：LLM 不直接握笔——五段分工

语言 token 是低带宽、离散、缺乏空间精度的控制通道，LLM 适合艺术总监职责（画什么/为什么/先处理什么），不适合生成大量精确坐标、水量、压力与曲率。分工：

- **LLM = 艺术总监**（题材、风格策略、技法解释、是否重新规划）
- **绘画策略模型 = 熟练画家**（基于目标表征 + 当前介质状态 + 人类过程先验，提出下一组动作）
- **连续优化器 = 手眼协调**（微调曲线、宽度、压力、水量、颜色、时机）
- **正向引擎 = 真实世界**（执行并产生介质后果）
- **未来状态预测器 = 经验**（预估干后结果与失控风险）

这也明确了蒸馏尖峰的产物定位：它是"绘画策略模型 + 未来状态预测器"两段的训练数据来源。
