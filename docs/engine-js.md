# JS 介质引擎实现说明（Phase 0 交付）

> 对应 `src/` 代码；规格见 `docs/engine.md` 与 `docs/watercolor_engine_spec.md`。
> 演进注：本文档为 Phase 0 交付基线（RGB 系统）。其后新增：16 波段光谱系统与六部分层重构（`chronicle/04-光谱色彩与分层重构.md`）。缺口 backlog 与协议 v0.2 见 `docs/engine.md`；升级缝正式规格见 `docs/architecture.md`。

## 数据结构（640×480 网格，Float32Array）

| 场 | 含义 | 说明 |
|---|---|---|
| `W` | 水量 0..2 | 蒸发、流动、冻结的载体 |
| `Pr/Pg/Pb` | 溶液颜料 | **存 K·d = (1-R)²/(2R)·amount**（KM 单常数，见渲染节）；`Pm` 为溶液质量 d |
| `Dr/Dg/Db` | 沉积颜料 | 已固着纸面；`Dm` 为沉积质量（KM 需要 K·d 与 d 分开） |
| `M` | 湿掩码 0/1 | 限定模拟 bbox；扩张 = 毛细润湿 |
| `ux/uy` | 流速 | 压力梯度 + 重力 + 纸纹湍流 |
| `H/C/G/F` | 纸 | 高度 / 持水容量 / 中频颗粒 / 高频细颗粒（granulation 尺度） |

## 每步管线（engine.js `_stepOnce`）

1. **流场**：u = −∇W·kPress + 重力 + 纸纹扰动
2. **水半拉格朗日平流 + 扩散**（bbox 限定，边界 CLAMP）
3. **掩码扩张**：W > θ 的格并入 M（清水前锋）
4. **颜料半拉格朗日平流**（pigAdv 0.65 < 水 0.9 → 颜料滞后于水）
5. **沉积**：deposit × (0.4+1.2·staining) × (1 − exposure·(H−0.5)) × (1+gran·细颗粒)（**bugfix：纸谷多吸附、纸峰少吸附，Curtis §4.5 的 1−σ·h**）
6. **前缘沉积**：本步新湿格把颜料钉成环（回流环）
7. **湿区边缘加深**：M − blur(M) 的**内侧**边带（**bugfix：原极性反，edgeK 恒空转**）+ 蒸发内侧加速（咖啡环增强）
8. **蒸发**：内侧边缘先干（evapEdge 加速）+ 咖啡环拉取（bugfix 后作用于湿区内侧边带）
9. **冻结**：W < ε → P 全并入 D，M 清零；bbox 失效后走全域尾水蒸发

## 回流开花算子（bloom）——迭代史

目标签名：**深色锯齿蕾丝环 + 浅色水渍心**。经历了 6 版迭代，教训记录如下：

| 版本 | 做法 | 失败原因 |
|---|---|---|
| v5 径向高斯推挤 | 半拉格朗日沿径向采样 | 位移剖面是"解压"的：心部小、前沿大 → 颜料摊薄不堆积 |
| v6 压缩式剖面 | ramp = 1−d/Rθ | 采样点穿过中心拉到对侧，把背景颜料拉回滴心（心浓边淡） |
| v7 径向钳位取样 | sd = max(0, d−disp) | **均匀场上推均匀颜料 = 还是均匀**：插值采样不守恒，无环可成 |
| v8 显式搬运 | 内区 P 扣走 → 堆到前沿 D | 只搬了溶液 P；滴落时 65% 颜料已沉积为 D，内区仍最暗 |
| v9 P+D 一起搬 | 再润湿重溶语义 | 环成了；单格四舍五入 → 像素阶梯 + 细线像描边 |
| v10-13 双线性溅射 + 解析增强 | 多格沉积带 + 外推光环 + ghost ring + 纸纹蕾丝 | 闭环 ✓ 蕾丝半成立；瓣形偏机械 |

**最终配方**（pushPigmentRadial）：
1. 前沿半径按角度噪声调制 Rθ = r·(1+0.42·(nA−0.5)·2)，nA = 0.7·低频瓣 + 0.3·高频次级瓣（2 倍频）
2. 内区 (d<Rθ) 的 P 与 D 各搬走 ~45%（噪声调制），双线性溅射到前沿沉积带（3 格加权，瓣尖更浓）
3. 外推光环（暗线外 8px 衰减）+ 次级内潮线（0.62Rθ，极淡）
4. 解析增强：|d−Rθ|<3.5 的环带按"环境颜料 × 纸纹细噪"钉沉积 → **闭环由构造保证**
5. 滴心 (d<0.75Rθ) 稀释到 30% → 浅色水渍心（随角度，不切进花瓣）

经验：**回流花边的灵魂是被"输运"出去的颜料，不是被冲淡的中心**；且显式搬运（质量守恒）比场采样可靠得多。

## 渲染（render.js）

- **颜料复合用 KM 单常数**（规格文档 §3 替代①）：每通道存 K·d（K = (1-R)²/(2R)，depositMask 时写入），质量 d 单独存（Pm/Dm）——KM 需要两者分开：
  `R_c = (1 - Rg·(a - b·coth(b·m))) / (a + b·coth(b·m) - Rg)`，a = 1 + (K·d)/m，b = sqrt(a²-1)，Rg = 纸色
- **为什么换掉 exp(-absorb·(1-rgb)) 模型**：exp 模型的通道吸收比固定为 (1-r)/(1-g)，饱和色（大红/深红）的色相偏差高达 0.55-0.59（色卡数值校验实锤）；KM 的 (1-R)²/2R 通道对比放大一个量级，同测最大偏差降到 0.10（象牙黑 0.000）
- **边缘沉积线在渲染侧实现**（engine.md 工件2 原文）：颜料软 mask → box blur → 相减得**内侧**边缘带 → 纸纹噪声调制宽度 → 加深。只取内侧（pmask−pblur），外侧白纸不被染灰
- 颗粒聚集：细颗粒 F × 纸谷偏置 × 颜料密度
- 2x 双线性上采样到 1280×960；输出钳位 [0,1]
- 浓度量程：KM 需要旧 exp 模型约 3.3 倍的颜料量（场景 amount 已统一重调）

## 笔触协议（strokes.js → engine 沉积）

| type | 实现 |
|---|---|
| wet-wash / glaze | **两条路径**：`region`（有机 blob）或 `path+radius(+radiusEnd)`（**条带扫笔 ribbon**：宽度首尾插值 × 压力包络(入锋窄→腹宽→收笔尖) × 沿程 fbm 抖动；路径先 Chaikin×2 圆角消折点尖角） |
| dry-brush | 沿路径**泪滴戳**（沿笔向、头圆尾尖）+ 间距/半径/朝向抖动 + 沿笔势条状飞白；支持 `clip: "last-ribbon"` 把纹理层裁剪在上一条 ribbon 内（纹理不再定义轮廓——树干"毛毛虫"的根治手段） |
| spatter | 幂律尺寸 + 随机拉长 |
| re-wet | **pushPigmentRadial 回流算子 + 清水注入** |
| lift | 沿擦拭方向（`dir`）拉伸的条纹残留 + P/D 按比例移除 |

## 关键参数（engine.p 默认值）

- 流动：kPress 0.4、advCoef 0.9、pigAdv 0.65、kDiff 0.075、theta 0.10、gravity 0.025
- 介质：deposit 0.028、exposure 1.5、frontDeposit 0.18、edgeK 0.45、evap 0.010、evapEdge 2.5、epsDry 0.004
- 渲染：absorb 2.2、edgeDarken 0.38、edgeBlur 4、granShade 0.22、wetDarken 0.07

## 性能

- 640×480，29-31 笔 ≈ 4800 步 ≈ 55-65 秒（含每 60 步渲染一帧 evolution）
- 干燥 600 步（10s 时间线）+ 20 帧渲染 ≈ 3 秒
- 优化空间：bbox 已用；半拉格朗日可加 |u|<ε 短路；Worker 并行可行但非必需

## 已知问题（诚实清单）

1. **物体笔触品味**：树冠扇贝轮廓、树干断续圆戳、草丛方向——引擎正确渲染了笔触，但**笔触本身的设计**（半径分布、方向、飞白）还停在"印章"水平。这正是 Phase 1 LLM 笔序 + vision 迭代要解决的，属于 agent 层而非引擎层。
2. bloom 瓣形偏机械（星形 vs 圆润菜花瓣）、两朵大小雷同；心部仍偏白。
3. 颗粒纹理与纸纹的方向性绑定偏弱（当前是细噪 × 纸谷，非纤维方向）。
4. 干皴飞白、咖啡环、洗色残留已上线但仍是"纹理层"：与压力曲线、蒸发历史、笔速的因果耦合不足（vision 建议：同一组笔触参数驱动三种痕迹）。
5. `_T.fill(0)` 每步全图清零、bbox 收紧扫描每 30 步一次——可进一步优化。
6. lift 无"起笔/收笔处颜料推挤堆积"的二次效果。

## 开发日志：踩过的坑

- **GIF 电视雪花（已修）**：两个 bug——① LZW 字典涨满 4096 后未发 clear 重置（12 位码溢出）；② 码宽切换时机：编码器加条目比解码器早一个码，切换条件必须用 `dictSize === (1<<codeSize)+1` 而非 `1<<codeSize`。用 Pillow 的 C 解码器源码（GifDecode.c）做权威裁判逐位定位；`demo/test-gif.js` + PIL 覆盖 511/1023/2047/4096 全部边界。
- **补色吸收模型**：颜料 RGB 存成补色吸收量 (1-r)·amount——早期直接存 r 导致天空渲染成赭色。
- **滑动窗口 box blur**：初始 acc 必须只累加第一个窗口（x0-rad..x0+rad），早期累加整行 → 水场爆炸为负值。
- **画布边缘永不蒸发**：bbox 循环边界把最外圈排除在蒸发/冻结之外 → 边缘成永久水库反向补给，水量永不归零。
- **回流算子六版迭代**（均匀场插值不守恒、采样穿过中心、只搬溶液不搬沉积层……）详见上方"回流开花算子"一节。
