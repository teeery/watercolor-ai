# 教学回放 MVP（Phase 1 第一刀）

> 决策（用户拍板）：第一刀切"不会画的"——**教学回放**。本文件是范围切割：做什么、不做什么、验收标准。品味观前提见 `docs/taste.md`。

## 一句话

把**已验收**的 31 笔手绘 demo（`demo/scene.js`：整体 6.5/10、背景湿铺 8/10、回流开花特写 6.5-7/10）变成第一堂课：逐笔回放 + 每笔一句"为什么"，不会画的人跟着学。

## 为什么第一刀切这里

- 付费意愿最直接（用户要学东西，不是看热闹）；
- 不需要大师供给——**教材已经存在且已验收**（人手绘的 31 笔，质量有 vision 独立评分背书）；
- 不需要网络效应，一个人也能成立；
- 每个跟着画的人都在免费产生笔迹数据（为 taste.md 的 L1 攒种子）；
- 最省：不动引擎、不接 agent 循环，先验证"过程即课堂"这个产品假设。

## MVP 内容

1. **第一堂课 = `demo/scene.js` 的 31 笔**。教材不改，质量已验收。
2. **回放即课堂**：逐笔回放，每笔停一下，显示三样——这笔画了什么（画布前后对照）、怎么画的（配方：颜料/水量/笔法/等多久）、**为什么**（narration）。
3. **五段阶段讲解**：按 `agent-loop.md` 的阶段制把 31 笔切成五段（构图/铺色/湿画/干画/收尾），每段开头一段讲解：先湿后干、由浅入深、趁湿滴清水、干皴造细节、洗色救场。
4. **同步临摹卡**：每笔一张配方卡，用户拿真纸真颜料跟着画——回放按笔暂停，节奏即教学节奏。
5. **救场戏是教学点**：`lift` 洗色、两朵回流开花、重颗粒 puddle——"画错了怎么办"的现场教材，与诚实守则天然咬合。

## 诚实约束（不可破）

- **narration 必须锚在真实 stroke 数据上**：为什么这层 `water: 0.7`——因为天空要一次湿铺盖过、先湿后干；禁止编造画布上不存在的过程。每条讲解能指到对应的 stroke 字段。
- **不改引擎、不伪造过程**：回放帧 = 引擎真渲染，救场、改砸如实呈现。
- narration 一次性生成 + 人审，不把 LLM 放进回放现场（现场无幻觉风险）。

## 明确的"不做"（MVP 之外，防止范围蔓延）

- 不做 LLM 现场画画（那是 agent 循环主体，后一步）；
- 不做用户笔迹采集与手拟合（L1 后话）；
- 不做账号 / 支付 / 社交传播；
- 不做移动端；
- 不做已故大师笔迹反推（研究问题）。

## 技术形态（最省方案）

- Node 预渲染逐笔帧（引擎已有帧导出能力）+ narration 时间线 JSON + **静态网页播放器**（帧 + 讲解 + 配方卡，前进/后退/按笔暂停）；
- 不移植引擎到浏览器（Phase 2 的"引擎运行位置"开放问题照旧不碰）；
- LLM 只用来写 narration，一次性、可审。

## 验收

- 一个不会水彩的人看完 31 笔回放，能说清三件事：为什么先画天空、为什么趁湿滴清水、洗色（lift）是干什么的；
- 每条 narration 都能指回对应的 stroke 数据；
- 全部静态文件，本地双击打开即可看。

## 施工顺序

1. 定 stroke JSON 协议的教学版最小子集（Phase 1 第一项本来就该做）；
2. 渲染逐笔帧 + 生成回放时间线 JSON；
3. 生成 31 笔 narration + 五段阶段讲解 → 人审；
4. 静态播放器页；
5. 按验收标准走查。
