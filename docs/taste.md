# 品味观与手文件

> 多轮讨论沉淀（品味 × 产品）。一句话：**品味不生成、不量化；品味被继承、被选择、被变现。人是唯一神谕。**
> 本文件是后续"手文件"与产品四档工作的规格前提；与 `paradigm.md`、`agent-loop.md`、`lessons.md` 并列。

## 讨论得出的三个裁决

1. **品味不是 agent 的属性，是数据 + 参数。** "克服手抖"还是"保留手抖"，本质都是人放的参数——不存在"AI 的品味"这个问题。因此"提高 agent 的品味"的正解不是让模型更有品味，而是把人的品味做成**可沉淀、可继承、可替换**的格式。
2. **品味不可量化，但可选择。** rubric 是给品味的尸体量尺寸；传统 = 历史的选择；画派 = 手文件的集合；用户是藏家。
3. **品味会变，且有方向。** 画家长大都是由巧入拙（敢用三笔说完三十笔的话）。agent 的品味是一条轨迹（更简、更敢、留白更多），不是静态风格库；风格库只是起点。

## 手文件（hand file）

**定义**：一组有性格的参数签名，回答"这个画家每次都怎么偏"：

- 手抖幅度与分布（全程轻颤？收尾加剧？）
- 水量偏差（永远多放一点水？）
- 边缘犹豫度（收尾毛糙 / 边缘死板）
- 留白倾向（舍不舍得留）
- 救场习惯（lift 洗色 / 补一笔 / 就让它花）
- 颜料忠诚度（哪几支颜料反复用）
- 笔序节奏（先湿后干？湿铺敢不敢一大笔盖过去？）

**四条"真实之手"性质**（来自"介质真实但不必物理"的推广：**手必须真实，但不必是血肉**）：

| 性质 | 含义 | 系统里怎么验证 |
|---|---|---|
| 持久 | 同一只手的签名跨作品成立 | 两份 recipe 出自同一手文件，观感同一人 |
| 有性格 | 偏差有方向，不是白噪声 | 手文件参数非全零；白噪声 = 没手 |
| 随状态而变 | 同计划不同"心情"不同结果 | 状态参数（呼吸/疲劳代理）进笔 |
| 会积累 | 画得越多，手越老 | 手文件随作品数演化（版本轨迹） |

agent 不"有"品味，agent **装载**品味。

**理想手 ≠ 零噪声手。** 缺陷是被挑选的，不是被消除的：零噪声画出的水彩是死画（本项目起点）。理想化 = 保留长出生命的缺陷（轻颤、水偏多、收尾犹豫），消除杀死画的缺陷（水失控成泥、暗部糊死、碎笔）。**选择者是人的品味**——理想手永远是人的作品，不是数学的极限。

**手文件的终态不是静态参数表。** 参数表只是 L0 起步（人调）。终态是学出来的映射：从笔迹拟合（Graves 2013 手写生成已证明可行——有性格、不可复现、永远同一人），且随作品演化"变老"。学习阶梯 L0-L4 见文末。

**第一份实例**：`demo/scene.js` 的 31 笔（人手绘）。反推的观察：水量两极（湿铺 0.7-0.9 / 干皴 0.13-0.3）、湿铺先行、天空两条大扫笔敢盖过远山顶部、重颗粒群青（granulation 1.0）敢留 puddle、一处 `lift` 洗色救场、颜料组固定（天蓝系 / 树绿系 / 赭棕系）。这就是"这只手"的雏形记录。

## 角色划分：配合问题的收缩

> 最初的问题"VLM 和 LLM 和画出来的东西能配合好吗"的答案：**别让三个模型对齐，让一份手文件贯穿三个模块。**

| 组件 | 角色 | 不做什么 |
|---|---|---|
| LLM | 意图翻译 + 明度规划（价值草稿先行） | 不发明风格、不伪造介质、不猜画布状态 |
| 引擎 | 水（介质唯一真相） | 不构图 |
| **手文件** | 签名（品味的唯一载体） | —— |
| VLM | 阶段裁判：对照价值草稿判断"这一步对没对" | 不当美学法官、不打绝对分、只做相对选择（3 选 1） |

配合的对象从"三个智能体对齐"变成"一个文件穿过三台机器"——这是可测的。品味一词从此退出技术文档：它回到人身上，它本来就在人身上。

## VLA 与真绘画的差别（哪些缝能补，哪些不补）

1. **人是同一块组织，我们是串口线。** 感知/情绪/记忆/动作长在同一种连续介质里；VLA 是三个数字模块用语言对接——语言是带宽最窄的序列化格式。每条缝（VLM→语言→LLM，LLM→语言→引擎）都在漏掉空间与身体。
2. **身体记忆不经过语言。** 庖丁解牛"官知止而神欲行"；画家的模型长在手腕里。agent 没有可以积累经验的肉——引擎每画一笔只是执行参数，不更新自己。
3. **人只有一具身体和一生。** 每幅画都是同一只正在老化的手画的；"人书俱老"。agent 每次会话都是一具新尸体——除非把手持久化。
4. **人不能撤销，才有胆量。** 留白敢留、一笔敢过，全部以不可逆为前提。一个永远可以 undo 的画家，品格上是残的。
5. **状态即风格。** 触感、空气、心情的本质不是"更丰富的输入"，是状态直接进笔——呼吸进笔锋，疲惫进水量。

**能补的**：1（手文件贯穿）、2（手文件随作品演化）、3（持久化）、5（状态参数）——四条性质可造。
**不补的**：疼痛、恐惧、必死。agent 不是来替代画家的，是**学徒**——师承传手，不传魂。

## 品味发生在哪个瞬间

裁决：水自己流是介质特性（油画凝固同理），不是品味。品味在于**意图里先住着对介质的预期**——预演。LLM 决定"趁湿叠一层群青"时，如果没预演"这层会回流、会开花、边缘会爬"，决定就是平庸的。"意在笔先"的"先"不是时间上的先，是**意图里先住着一个预期的偏差**。

郑板桥：眼中之竹（VLM）/ 胸中之竹（LLM）/ 手中之竹（引擎）**永不相等**，而"趣在法外"——品味恰恰住在计划之外的那一段。所以三者**不该配合到彼此相等**，相等了就死了。VLM 最像人的角色不是裁判，是**那个能认出意外的人**（休谟的品酒师：闻出桶底那根拴着皮带的铁钥匙）。

## 产品四档（护城河 = 参与权 + 师承链）

diffusion 生成即完成、不可插手；**水彩画是活的，直到它干**。时间线谁都能录，参与权别人复制不了。

三类用户——不会画的（徒）、大画家（师）、爱好者（玩家）——不是三个市场，是**一条师承链上的三个角色**：

```
大画家（师）──捐手/授权──→ 理想手与传承手（品味资产）
                                  │
        ┌─────────────────────────┼──────────────────────┐
        ↓                         ↓                      ↓
   不会画的（徒）           爱好者（玩家）          社交传播
   回放即课堂               玩手、混手、挑战        晒"我的画"
   同步临摹                  "我的句子×大师的手"      拉新
        │                         │                      │
        └──────────── 名声/收入/学生 ────────────────────┘
                         ↑ 供养师傅 → 更多大师愿意捐手
```

| 档 | 形态 | 逻辑 |
|---|---|---|
| **看** | 他人作画回放，免费引流 | 救场戏是内容：agent 被允许犯错、撤笔、救回——诚实守则与内容天然咬合，不是瑕疵记录，是戏 |
| **画** | 一句话 + 你选的手 → 完整水彩 + 时间线 | 付费/额度；手文件即产品资产 |
| **同画** | 画到一半，用户亲手加一笔 / 选方向 | 那幅画上有你的手；参与权是唯一别人复制不了的 |
| **传** | 大画家捐手 → 拟合他的手 → 他的手继续画新作品；初学者回放临摹 | 师承经济学：大师换永生（死后还能画）、分成（其手的作品提成）、徒弟（回放即虚拟师父，粉丝即徒弟）；传承靠师的利益设计，不靠情怀说服 |

**师承经济学闭合"大师不一定愿意"的问题**：不愿捐手的大师，看到同行的手活着、被一万个初学者临摹，很难不心动。

**诚实工程前提（现在说破）**：成画不是笔迹数据——拟合手需要**过程数据**（笔在时间里的轨迹与水量），不是完成品。所以"传"的第一版是**在世画家的自愿捐赠**（画几笔 → 拟合）；已故大师的手只能从作画视频反推，是研究问题、素材存在、后话。

品味闭环：用户选哪只手、在哪个瞬间插手、留哪一笔——**用户品味直接变现**。品味不可量化，但品味可以选择，选择可以收费。

## 学习阶梯（品味与手的参数作者权迁移）

"怎么又回到参数了"的答案是：**参数的值该由数据和选择自己长出来，而不是人列清单。** 人工智能史的主线是参数作者权的迁移——人写规则 → 数据写参数 → **偏好写参数**（RLHF：人只做三选一，品味模型从选择里长出来）。本项目照搬这条原理，规模缩小一千倍，因为产品天生免费收偏好数据（每次 keep-best 就是一次标注）。

| 阶梯 | 手 | 品味 | 谁在学 |
|---|---|---|---|
| L0 现在 | 静态手文件（人调） | rubric + VLM 打分 | 没人学 |
| L1 学徒 | 小模型拟合人的笔迹（状态+意图→偏差分布） | 保留 VLM 阶段裁判 | 手在学人的手 |
| L2 画廊主 | 手继续演化 | 每次 keep-best 选择存下，训练本地小品味模型 | 品味在学人的选择 |
| L3 画家 | 手 = 策略，在引擎里练（引擎是环境，品味模型是奖励） | 品味模型快裁判，VLM 抽查，人终审 | 整个 agent 在学 |
| L4 私教 | 手随用户 | 每个用户的选择训练出"他"的品味模型 | 它学你的品味 |

工程现实：全部阶梯都是**小模型 + 小数据**，CPU 能训、零依赖 JS 能推理；不碰 GPU、不 fine-tune 大模型。L2 顺带治 lessons 第 7 条（免费 VLM 限流断环：本地品味模型兜底）。

## 开放问题

- 价值草稿门禁的形式（LLM 出明度计划 → VLM 对照裁决 → 才动笔）
- 同画的介入粒度（选方向 / 加一笔 / 改参数）
- 手文件演化的验收：多少幅画之后"手变老了"可见
- 已故大师笔迹反推（作画视频 → 过程数据）——研究问题；成品图反推过程已有先例（Inverse Painting，见 `docs/predecessors-agents.md` 册二），stroke 级翻译仍是缺口
- **第一刀（已定）**：不会画的——教学回放 MVP，范围切割见 `docs/teaching-mvp.md`（教材 = 已验收的 31 笔手绘 demo；narration 锚在 stroke 数据上；不做现场画画 / 笔迹采集 / 账号支付）
