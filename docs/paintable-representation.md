# 可绘制表征与逆水彩分解（Paintable Representation）

> 场景图解决语义，不解决绘画。"天空、房屋、树、麦田"的对象分割只回答"这里是什么"，不回答"这里怎么画"。
> 意图层与笔序层之间的中间表示不能是场景图，必须是**可绘制表征 Z**。

## 画家真正操作的是什么

不是对象，而是十个绘画量：

1. **明度块**——大中小尺度的黑白灰布局，不是"树冠是绿的"。
2. **冷暖关系**——色温的进退，决定空间和光线。
3. **正形与负形**——形体的形状和它周围的形状同样被设计。
4. **边缘归属**——每个边缘属于谁（形体的、阴影的、投影的），软硬如何。
5. **透明色层**——颜色是叠出来的，层与层的顺序就是绘画结构。
6. **留白拓扑**——哪里必须绝对纸白，负形的边界画在哪。
7. **笔势方向场**——笔触跟着形体的走势走，方向即体积。
8. **视觉重心**——哪里是第一眼，哪里可以糊。
9. **局部对比度**——焦点区域与休止区域的反差分配。
10. **湿边与干边的时序关系**——哪笔趁湿接、哪笔等干后落。

## 定义：Z = {V, L, E, O, T, Q, S, M}

| 符号 | 名称 | 内容 | 引擎/协议落点 |
|---|---|---|---|
| V | 多尺度明度场 | 大块布局、局部体积、微对比 | 渲染结果可度量；glaze 层数与浓度 |
| L | 透明色层及其顺序 | 每层的色相/冷暖/浓度、叠放次序 | stroke 序列的 glaze 叠放 + 干燥时序 |
| E | 边缘场 | 每个边缘的软硬与归属 | stroke 边缘参数；湿边/干边选择 |
| O | 遮挡与拓扑 | 谁盖谁、封闭轮廓、T 接 | 笔序先后（先背景后前景） |
| T | 笔触方向场 | 形体走势方向，笔势跟形 | `motion` 方向字段 |
| Q | 纸白与负形约束 | 留白拓扑、负形边界 | 协议预留白（不落笔区域） |
| S | 视觉显著性 | 重心、焦点、休止区 | 阶段预算分配（重点区域多花笔数） |
| M | 建议介质技法 | 湿铺/干皴/回流/颗粒/洗色与时机 | stroke `type` 选择 |

十个绘画量与 Z 的映射：明度块、局部对比度 → V；冷暖 → L 的色相序列（Z 无专门色相字段，冷暖由 L 承载——将来若不够可加 C 字段，属延展方向）；正形 → O，负形/留白 → Q；边缘归属 → E；透明色层 → L；笔势 → T；重心 → S；湿干时序 → M。

## 核心任务：逆水彩分解

- 引擎是**前向模拟**（stroke → 画面）。Z 定义的是逆向问题：给定视觉结果，推断它可能由哪几层洗色、哪次留白、哪种湿度、哪些干笔形成。
- "这里是一栋房子"（语义识别）≠"这块冷灰由一层钴蓝洗色在纸白上形成、左缘留白、趁湿接入暖色"（绘画分解）。
- 与"神经升级缝"路线四（inverse painting：扩散模型当老师）是同一个问题：把 diffusion 生成的目标图拿去逆水彩分解，就是把高级算法接进 Z 框架的入口。
- 与可画性（`docs/paintability.md`）的**对偶**：可画性 = 引擎动作集合的前向可达域；逆水彩分解 = 目标在 Z 空间的逆向投影。只有落在可达域内的 Z 才有解——可画性基准给 Z 的可行性划界。

## 在系统里的位置

- **意图层与笔序层之间的中间层**：LLM 先产出 Z，规划器再把 Z 编译为 stroke 计划（`docs/agent-loop.md` 第一步"构图"的升级：从"直接规划笔序"变为"先 Z 后笔序"）。
- 双通道：语义通道（对象识别）→ 绘画通道（Z 分解）。语义帮助构建 Z，但**不等于** Z。
- 第一版不要求全套：先让 LLM 产出简版 Z（V/L/E/T/Q 五个头），其余后补——这是延展方向，不是 Phase 1 门槛。

## 验证

- Z 的可验证性：Z → 编译 stroke → 引擎渲染 → 与原图对照（可画性基准方法的延伸）。
- 批评粒度再提前一层：vision 批评"这个边缘归属错了"比"缺背鳍"更接近执行——把 `docs/agent-loop.md` 的 stroke 级批评升级到 Z 级。
