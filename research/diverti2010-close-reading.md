# DiVerdi 2010 精读复核(brush 分支,对照 v2 §3 毛层)

> 材料:`research/1889863.1889889.pdf`(用户提供,ACM 版)+ `research/diverti2010.txt`(提取 8 页)。
> DiVerdi, Krishnaswamy, Mech, Ito, "Industrial-strength painting with a virtual bristle brush", VRST 2010(Adobe 商业画笔内核)。

## 1. 方法骨架(引擎术语)

- **毛**:逐根 **DER 模型**(弯曲 + 扭转能,直 rest 无扭转),完全隐式 backward-Euler + 块三对角直接求解;
- **足迹**:quad strip 正交投影;**毛厚反比根数**保覆盖(根少则粗,总覆盖面积不变);
- **压力**:pressure → height 映射依赖 stiffness;非惯性系抹加速度只留速度做摩擦。

## 3. 可抄清单(性价比序,几乎免费)

1. **非惯性系抹加速度只留速度**(§3.4)——已半抄,确认 lagCoef 只吃速度不吃加速度。JS 一行;
2. **毛厚反比根数保覆盖**(§4.1)——最值:N 小时加大毛缘段宽,双轨边不随 N 缩水。1 行 JS;
3. **压力→宽度必须过 stiffness**(§3.6 Fig3)——确认 `width = f(p, spring)` 显式次序,而非顺序相乘;
4. **pickup 独立消耗**(§4.2)——v2.1 脏笔直接翻:pickup 桶独立扣,小 pickup 出短脏痕;
5. **bezier 输入 + 线性毛插值**(§4.1)——佐证弧长参数化,毛几何线性插值可接受;
6. **塑性屈服 eq4**(§3.3,极简)——可给 splay/毛缘"记忆"做可选升维,低优先;
7. **参数最小化 load/wetness/mixing**(§4.2)——佐证协议三参设计。

## 4. 拒绝清单

- DER 逐根 + 块三对角隐式求解(§3.1):30µs/毛,JS 无稀疏求解,预算外;
- 连续碰撞 + Bridson 摩擦 + 位置/速度投影(§3.2):每粒子迭代,3D;
- 完全隐式 + 雅可比(§3.1):我们以指数释放 + 钳制等价,更便宜;
- 3D stylus 倾角映射(§3.6):2D 无 tilt;
- Pudet 矢量扫掠包络(§4.1):无矢量输出需求;
- 多核流水线 / SSE 32-bit(§5.1/§4.2):单线程 8-bit;
- 塑性 reset 工作流(§3.3):他自证艺术家嫌 confusing。

## 5. 纠错清单(v2 需改)

1. **§3 "β=1 = 全物理"表述不准确**:β 扫过的是"非惯性系抹除强度",β=1 只是全惯性,到不了 DER——措辞改"β=1 = 全滞后(惯性完整)";
2. **毛缘浓度 1.3-1.6× 是 DAB 独家**,DiVerdi 同样无密度函数,别挂他(Wetbrush 精读已纠一次);
3. **腹池/毛缘二分是自创**:他单 quad strip 投影,干/湿靠 thickness 单轴扫——建议用"**有效毛厚**"统一过渡,而非硬切双 mask;
4. **splay 迟滞应标注为"替他砍毛间碰撞的补偿"**,非抄他;
5. **附录 D"无人可抄"对 DiVerdi 不成立**:应改为"笔的动力学有 DiVerdi 一家直接蓝本,抄抽象(非惯性系/毛厚覆盖/宽度接线/pickup 消耗),拒 DER 求解";
6. **v0.3 补 stiffness→宽度接线**:`width = f(p, spring)` 显式次序写入协议字段语义。
