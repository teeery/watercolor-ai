# Wetbrush 2015 精读复核（brush 分支,对 v2 毛层与空间水库的原文对照）

> 材料:`research/2816795.2818066.pdf`(ACM 原件,15.3MB,用户提供;文本提取 `research/wetbrush2015.txt`,11 页)。
> Chen, Kim, Ito, Wang, "Wetbrush: GPU-based 3D painting simulation at the bristle level", SIGGRAPH Asia 2015。
> 方法:子代理原文精读 → 主代理整合。本文只记录与笔刷动力学 v2 相关的结论。

## 1. 模型骨架(用我们术语复述)

- **刷毛**(§4.1):每根毛 = 一串顶点(≈10)+ 密集采样点(128/根,间隙 <1px,Hermite + Bishop 最小扭转标架);40–600 根/支。**非惯性系**:在笔/毛局部系积分,系数 β ∈ [0, 0.1] 缩放惯性加速度(β=0 = 刚体随笔),再加 PBD 抗拉/抗弯约束 + 密度约束防毛簇无限密。
- **接触脚印**(§4.1/§4.3):**无显式脚印 mask**。液体 = 粒子(距毛 < D0=1cm,亚像素)+ 密度场(远处,像素级)的联合表示;毛采样点栅格化为密度/速度场作边界;脚印 = 粒子被毛拖带 + 压开液面的痕迹。
- **液体表示与互转**(§3/§4.2/§4.3):边界在距离 D0;近→FLIP/PIC 粒子(20 万–200 万),远→3D 密度场(semi-Lagrangian 平流);经 joint pressure projection 耦合;网格→粒子(每格 27 分层候选采样)、粒子→网格(核累加,式 15/16)。
- **笔↔画布转移**(§5):蘸取 = 毛采样点"负载 mj / 容量 Mj",容量随毛密度 ψ 与到表面距离缩(式 12/13);m < M 吸粒子(饱和后仍混色 = 脏笔),m > (1+ε)M 发射粒子至下半球(ε=0.1 迟滞防抖)。颜料 = RYB 三通道 + 亮度保持混合(算法 2)。
- **大时间步**(§4.2/§5):固定点 Jacobi(算法 1:α=1,3 定点 = 6 Jacobi,前几迭代收敛最快)+ β 缩放 + 活性窗 128×128×32。

## 3. 油画 → 水彩迁移判断

- **能抄**(与介质无关的层):β 非惯性旋钮(纯运动学);毛负载/容量 + 吸放阈值(→ 3 桶水库,把"容量随毛密度缩"换成"容量随毛细/纸吸缩");RYB 亮度混合;干燥度标量 → 固体(→ gb/蒸发);活性窗思想。
- **不能抄**:FLIP/PIC 粒子 + 不可压密度场(水彩无自由油面,水吸进纸,无体积守恒目标);式 8 摩擦(油彩涂抹专属);D0 网格↔粒子互转(水彩里"远离笔的液体"已经渗进纸了);3D 体渲染。论文 §8 自己把 watercolor + percolation 列为 future work——水彩需要的纸吸收/毛细扩散/蒸发/粒重,是 Curtis 路线的活,不是 Wetbrush 的。

## 4. 可抄清单(性价比序)

1. **β 非惯性旋钮**(§4.1):tip 滞后改 β 参数化(0=刚体随笔,1=全物理)——给 lagCoef/kStiff 定标,一行改动;
2. **毛负载/容量 + 吸放阈值 ε=0.1**(式 12/13):reservoir.js 容量随 splay/贴纸缩,迟滞防抖;
3. **位置式粘附两遍混合**(式 10):pickup/负通量用位置式混合替代刚性 wicking 力——论文图 8 左显示刚力会发散,免调步长;
4. **RYB 亮度保持混色**(算法 2):蓝+黄=绿优于 RGB lerp → 记入 color 线 backlog;
5. **干燥度阈值 → 固体**(§4.2):gb 状态机的参数口径;
6. 活性窗 → 已对齐 M0,无需新动作。

## 5. 拒绝清单

- FLIP/PIC 粒子 + 不可压 pressure projection + 固定点 Jacobi:GPU 专属(200K–2M 粒子、原子操作),单线程 JS 预算外,且水彩无体积守恒目标;
- 逐根毛 Hermite + 128 采样 + Bishop 标架 + PBD 密度约束:40–600 根 ×128 采样,预算外,v2 已明确不做;
- 3D 体渲染/射线 AO:渲染侧,非引擎职责。

## 6. 纠错清单(v2 相悖处,需改 v2 文档)

1. **§3"抄 DAB/Wetbrush 的密度函数思想"是误认**:Wetbrush **没有**脚印密度函数(§7 明言批评 stamp map 方案);"边缘浓中间淡 1.3–1.6 倍"是 **DAB** 的经验来源。v2 §3 与附录 B 的挂名要改。
2. **"腹池+毛缘"与"粒子+密度场"不同构**:论文按"距毛远近"切分**同一液体**的两种数值表示(可互转、同守恒);v2 按"湿态主体/干态边缘"切分**两个沉积 mask 的语义角色**(永不互转)。只有弱类比:粒子↔亚像素毛缘细节、密度场↔粗腹池。§3 的类比表述要降格为"直觉借用",不当机制依据。
3. **N=32 毛出不了论文级脚印纹理**(40–600 根 ×128 采样 + 20 万粒子才出亚像素细节)——与我们"不做逐根物理"的定位一致,不必追;但验收里"双轨边/转角刮痕"应明确是**感知代理**而非亚像素仿真。
4. §4 负通量若实现成刚力会发散(论文图 8 左),按式 10 位置式混合实现。
5. 无重大原则性相悖:不做逐根物理、时间交错、守恒钳均与论文方向一致。论文"油彩高粘、笔走液止"→ 戳间液体近似冻结,顺带验证了 v2 §6 的压缩交错只须对蒸发上粗调度、无需流体子步。
