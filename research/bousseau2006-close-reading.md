# Bousseau 2006 精读复核(brush 分支)

> 材料:`research/bousseau2006.pdf`(INRIA 作者主页版,22.6MB)+ `research/bousseau2006.txt`(提取 9 页)。
> Bousseau, Kaplan, Thollot, Sillion, "Interactive watercolor rendering with temporal coherence and abstraction", NPAR 2006。

## 1. 前提纠错(重要)

论文**没有**湿度驱动扩散/浅水方程/稳态近似——三者皆无。它明确**拒绝**流体模拟与湿接湿扩散(§2:"diffusion requires a fluid simulation, and would certainly not be temporally coherent")。真实骨架是**静态图像滤波管线**:

- **抽象层**(§4.2):卡通着色+法线平滑(3D)/mean-shift 分割+形态学开闭(图像),压成均匀色块;
- **效果层**(§4.1):密度参数 d 改色 `C′ = C − (C − C²)(d − 1)`(§4.1.1);三层灰度纹理(湍流/颜料弥散/纸纹)独立调制 `d = 1 + b(T − 0.5)`(§4.1.2);梯度暗边、纸纹摆动、干笔阈值(§4.1.3);
- **时域**(§5):把颜料噪声纹**锚定到 3D 几何**而非屏幕,消"淋浴门"滑动——消的是纹理-物体错位,不是物理时间线抖动。

## 2. 可抄清单(性价比序)

1. **密度参数 d 统一接口**(§4.1.2):render 侧多层噪声统一套 `d = 1 + b(T−0.5)` → `C′ = C − (C−C²)(d−1)`,替代杂散 edgeDarken/granShade 魔数,每层独立 b。归 render/color 线。
2. **特征生灭连续化**(§5.2.1):frontDeposit/bloom 环"一步钉死"改 2-3 步 ramp 权重沉积;M0 静止短路重启平流时用 2-3 步淡入(滞回+斜坡)而非瞬时恢复——**这是我们 M0 计划的真实缺口**。
3. **抽象先行**(§4.2):agent 层加"先出均匀色块再画"的抽象校验(形态学开闭核 = 笔刷口径),引擎零改动。归 Phase 1 agent 层。

## 3. 拒绝清单

- 流体模拟他们就没做,无从抄;
- §5.1 物体空间贴纹理、§5.2 octave 无限变焦——需 3D 几何+移动相机,2D 纸面无此需求;
- 改色公式本身(比我们 KM 弱,已舍);
- 密度层是**静态贴图**非物理场,不能当"湿度驱动"抄。

## 4. 对 v2 / 计划的三条修正

1. **M0 静止短路的硬 on/off 恰是论文 §5.2 花大力气消的离散跳变**——补"重启连续性":滞回已有,缺淡入斜坡。归 perf/M0 工作流。
2. **§6 压缩交错 budget=90 定值封顶是离散量化**——应按弧长连续分配(慢段多步、快段少步已有),封顶改软上限,长笔的干燥差饱和问题随之缓解。
3. **哲学警示入诚实清单**:论文 §2 的"扩散必破坏时域相干"——我们的半拉格朗日+拉普拉斯是时域脆点,drying_timeline 的帧间跳变不是渲染 bug,而是扩散+离散采样的固有产物。Phase 2 时间线产品化时必须正视(缓解手段:特征生灭连续化、层级+reveal(Zheng 2017)、时间超采样)。
