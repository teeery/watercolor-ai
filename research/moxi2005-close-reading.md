# MoXi 2005 精读复核(brush 分支,对照 medium-upgrade M1 各向异性纸纹)

> 材料:`research/moxi.pdf`(用户提供)+ `research/moxi2005.txt`(提取 8 页)。
> Chu & Tai, "MoXi: Real-Time Ink Dispersion in Absorbent Paper", SIGGRAPH 2005。

## 1. 方法骨架(引擎术语)

- **纸三层**:surface(未吸墨库)/ flow(水+颜料渗流层)/ fixture(干后固着)≈ 我们的 reservoir + W/P + D。纸物理 = **标量渗透率 κ**(§5.3.1 式6)= 纸厚纹理 G + 明矾 A + 胶 g + 固着累积 h;**无显式纤维方向场**,方向性靠 pinning 线段纹理给"易流方向"。我们 H/C/G/F 已覆盖 G/C,缺 κ 与 pinning。
- **吸收**:surface→flow 供给 φ = clamp(s, 0, π−ρ),受**容纸度** max(1−ρ/λ, m) 调制(湿区低吸 → 浅边晕)。
- **毛细扩散**:LBE D2Q9(§4)bounce-back 做变渗透率(式5);低密度加权 ψ 弱化对流防负密度(式7-8);**pinning 阈值 σ** 做边界钉扎/粗糙化(§5.3.3 式9)。
- **颜料**:随水对流 + **阻滞**(|u| 低时 γ* 混回原处 = 纤维滞留,§5.4.2)+ **逐步固着**(按失水量 FixFactor,§5.4.3)。
- **实时**:LBE 全局部、无 Poisson 全局解 + GPU 纹理场迭代。JS 单线程只抄"全局部、禁全局压力解"。

## 2. 逐项对照(vs M1 计划)

| 论文机制 | 我们 M1 计划 | 判定 |
|---|---|---|
| 无方向场,靠标量 κ + pinning 线段 | Tx/Ty 低频噪声角度场 | 🔶 角度场是超集,但缺 κ 与 pinning 两标量 |
| 各向异性 = κ 阻塞 + ψ 弱对流 + σ 钉扎,非扩散张量 | kD∥ > kD⊥ + 毛细爬行 | ⚠️ 纯扩散张量 → 木纹;须补 σ 与 ψ |
| 容量 π 均匀 + 容纸度 max(1−ρ/λ) | C 场(fBm 空间变化) | ✅ C 更富;🔶 缺容纸度调制 |
| 阻滞 + 渐变固着 | 沉积线断裂 + 方向颗粒 | 🔶 断裂方向对,缺速度依赖阻滞与渐变固着 |

## 3. 可抄清单(性价比序)

1. **σ 钉扎阈值**(§5.3.3 式9,最值):毛细爬行第 2 趟改"沿纤维邻格已湿 且 ρ > σ",σ = lerp(q1 + G·q2 + P·q3, …)——直接治愈圆润前沿;
2. **容纸度 max(1−ρ/λ, m)**(§5.2):供给/沉积乘它 → 浅边晕,补进 mask;
3. **阻滞 SIMULATEHINDRANCE**(§5.4.2):`pigAdv ← lerp(旧, 平流后, lerp(1, γ, smoothstep(0, ς, |u|)))`,γ 乘纤维 |cos(θ−流向)| → 横纤维颜料滞留 = 方向颗粒 + 沉积断裂的物理版;
4. **SIMULATEFIXTURE**(§5.4.3):`FixFactor = max(失水比 × (1 − smoothstep(0, μ*, ρ)), η)`,替换 W<ε 二值冻结;
5. **ψ 低密度弱对流**(§5.3.2):`advCoef ×= smoothstep(α, 0, ρ)` 防前沿负密度;
6. **κ = g + h 堵塞反馈**:沉积量累计调低局部扩散 → 分支纹。

## 4. 拒绝清单

- LBE 本体(§4):半拉格朗日 + 显式扩散已局部够用;
- 表面/流层双层储水(§5.1):单 W 场已够(Curtis 同款);
- GPU 纹理管线、边界 trimming 隐式曲面(§6)、纸厚扫描:非介质机制;
- 明矾/胶作独立场(κ 式6 的 A/g 项):可折进 C/F。

## 5. 纠错清单(A 方案的修正建议,归 medium-upgrade 会话消费)

1. **kD∥ > kD⊥ 非 MoXi 各向异性来源**——是 κ 阻塞 + σ 钉扎。§A-2 降为辅助,主机制换 σ 钉扎 + 变渗透率,否则木纹滤镜风险实锤;
2. **沉积线断裂**的 |Tx·边缘法向| 是几何近似;改抄清单 #3(pigAdv 按 |u| 与纤维夹角打折)更物理;
3. **毛细爬行缺阈值**:σ 决定钉扎/去钉扎,直接照抄,否则爬行只是等距圆弧微扰;
4. **冻结是二值 W<ε**——渐变固着才对"颜料随纤维滞留";方向颗粒应嫁接此固着,而非只改 F 采样方向;
5. **Tx/Ty 角度场可保留**(比 MoXi 强),但须再补一张 **pinning 线段纹理**才能出 toe/分支,否则方向感只剩木纹。
